# 셀럽픽 레시피 쓰기

입력: CC BY 원본 영상 링크 + `shorts/out/자막_<id>.txt`(scan.py --full) 또는 리포트.
출력: `shorts/recipes/<이름>_<제품>.json` 최대 3개 + 제품 타임스탬프 표.

## 0. 고르기
- **한 원본 영상에서 최대 3개.** 셀럽이 직접 이유·사용법·효과를 말하는 제품만 고른다.
- 건강 효능을 주장해야 팔리는 제품(꿀, 지압 패치, 영양제 효능 등)은 피한다.
- 브랜드를 모르는 제품은 표에 "브랜드 미확인"이라고 적고, 비슷한 제품으로 찾게 한다.
- 각 제품의 **등장 시각(mm:ss)과 youtu.be/<id>?t=초 링크**를 표로 같이 준다. 사장님이 직접 찾는다.

## 1. 화면 제목 (title1 / title2) — 사장님 기존 쇼츠 스타일
- 두 줄, 줄당 6~10자. 짧고 세게. 전부 흰색(낭만있구미체, shorts/fonts에 넣어둠), 이름 강조색 없음.
- 공식: `[행동·상황]` / `[하는] [이름]` 또는 `[이름]의 [제품]` — 이름은 보통 둘째 줄 끝.
- 사장님 실제 제목: "게임하면서 / 비타민 먹는 츄", "발에서 냄새가 / 나본 적이 없다는 소미",
  "알약 못 넘기는 / 레드벨벳 슬기", "미숫가루 10년에 / 1번 먹는 한혜진", "츄의 겨울철 / 민낯 화장 필수템",
  "말랑이에 이름 붙여준다는 / 올데프 애니", "입냄새 나는 친구에게 / 선물해보세요"
- 의외성·숫자·고민(냄새, 못 넘기는, 10년에 1번)이 들어가면 반응이 좋았다.

## 2. TTS 대본 (자세한 분석: shorts/NARRATION.md)
- **3인칭 이야기꾼.** 반말 리액션 금지.
- 출연자는 **직업까지 붙여서**: "배우 박지현", "아이브 장원영". 이름만 쓰면 못 알아본다.
- **제품 이름은 말하지 않는다.** 정답은 셀럽이 클립에서 공개.
- 끝은 `~는데 / ~지만 / ~은? / ~이것은?` — 다음 클립으로 넘기는 궁금증.
- **영상에서 확인된 사실만.** 숫자·기간·상황("어릴 때 수영을 했던", "촬영장마다")으로 믿음을 준다.
- 구조: **반드시 TTS로 시작. TTS는 최대 2개.** 도입 TTS(인물 특징 + 상황 + 이것은?) → 클립 → 연결 TTS(짧게, "비결은") → 클립 (→ 클립). 전체 20~35초.
- 한 TTS는 25자 안팎. 연결 TTS는 10자 안팎.
- 끝맺음 TTS("제품 정보는 프로필 링크에") 넣지 않는다.

## 2-1. 색깔 강조 (highlight)
- `"highlight": ["말랑말랑", "외이도", "5분"]` — 자막에서 초록색으로 칠할 포인트 단어 3~5개(한 어절 안의 글자로). 숫자는 자동 강조.
- 제품 특징·효과·숫자 위주. 너무 많이 넣으면 촌스러움.

## 3. 컷 구간 (parts의 clip)
- `from`/`to`는 자막 문장을 **글자 그대로** 몇 어절 복사(띄어쓰기 무시하고 찾음).
- 셀럽이 제품을 말하거나 보여주는 핵심만. 군더더기·잡담은 빼서 빡빡하게.
- 한 클립 3~9초.

## 4. 업로드 캡션 (사장님 스타일 — 이 형식 그대로)
```
"caption": "배우 박지현이 늘 가방에 넣고 다니는 미니 빗 🪮",
"points": ["붙임머리도 엉킴 없이 술술 빗기는 돈모+나일론 브러시 ✨",
           "두피에 닿아도 하나도 안 아파서 매일 손이 가요 💆‍♀️"],
"hashtags": ["헤어브러시", "돈모브러시", "붙임머리", "왓츠인마이백"]
```
- caption: `[직업] [이름]이 [상황/습관] [제품 종류] [이모지]`
- points 2줄: ① 고민·상황 → 해결 ② 사용감·효과. 각각 끝에 이모지 하나. 셀럽이 한 말에서만.
- hashtags 4~5개: 출연자 이름은 자동으로 맨 앞. 제품 태그 위주.
- "상품 정보는 프로필 링크 N번에서도 확인할 수 있어요!", CC 출처, 쿠팡 파트너스 문구는 make_short.py가 자동으로 붙인다.

사장님이 예전에 쓴 캡션 예시:
```
소미가 발냄새 걱정 생겨서 찾은 애사비 풋샴푸 🍎
✓ 연습생 시절엔 없던 발냄새, 요즘 걱정돼서 선택 ✨
✓ 뿌리고 문지르기만 하면 끝, 상큼한 사과향까지 남는 개운함 🚿
```

## 5. 공통 설정 (현재 기본값)
```json
"theme": "celebpick", "sub_theme": "story_green", "clip_subs": true, "blur": true,
"google_voice": "ko-KR-Chirp3-HD-Kore", "google_rate": 1.3,
"media": ["auto"], "broll_offset": 0/1/2 (같은 영상 레시피끼리 다르게)
```
- `link_text`: `"프로필 링크 N번"` — 번호는 띄엄띄엄(예: 46, 53, 61). 사장님이 정하면 따른다.

## 6. 끝나고
- `python3 make_short.py recipes/X.json --check`로 구간이 잡히는지 확인.
- 사장님께: 제품 타임스탬프 표 + 캡션(복사용) + 맥 실행 명령(원래 쓰던 2단계 형식).
