# 내 사주 속 신살 찾기 (앱인토스 미니앱)

생일 하나로 사주에 숨은 신살(도화·역마·천을귀인…)을 찾아 캐릭터 카드로 보여 주는 미니앱입니다. 서버가 필요 없습니다. 계산은 모두 휴대폰에서 합니다.

| 화면 | 무료 | 광고 |
| --- | --- | --- |
| 대표 신살 카드 | 가장 드문 살 1개: 캐릭터, 별명, 100명 중 몇 명, 설명, 더 알아보기 | — |
| 숨은 신살 | 나머지 살 목록과 비율 | 보상형 광고 1회 (이 사주는 다음부터 계속 열림) |
| 페이지 맨 아래 | — | 배너 |

- 공유: "친구에게 내 살 자랑하기" → 토스 공유 링크(`intoss://hundo-sinsal`).
- 유료 연결: "훈도사주에서 평생 사주 보기" → 훈도사주 미니앱(`intoss://hundo-saju`). 두 미니앱 이름이 콘솔과 같아야 합니다.

## 코드

- 신살 엔진과 캐릭터 그림: 사이트의 `jojeong/lib/sinsal.ts`, `jojeong/public/sinsal/` 그대로.
- 생일 입력·저장·광고: 훈도사주 미니앱의 `hundo-toss/src` (`@common/…`).

```bash
npm install
npm run dev
npm run typecheck
npm run build    # tsc + vite build + ait build
npm run deploy   # 콘솔 API 키 필요
```

개발 도구의 모의 광고는 보상 이벤트를 보내지 않아서, 브라우저에서는 "광고 보고 숨은 신살 보기"가 열리지 않습니다. 토스 앱 QR 테스트에서 확인하세요.

## 출시 전에

1. 콘솔에 미니앱 `hundo-sinsal` 등록.
2. 인앱 광고 신청 → 보상형·배너 광고 그룹 ID를 `.env.local`의 `VITE_AD_REWARDED`, `VITE_AD_BANNER`에.
3. 토스 앱 QR 테스트: 광고 보상 → 숨은 신살 열림, 공유 링크, 훈도사주로 이동 확인.
