# 📡 Travel Deal Radar (MVP)

평소 가격보다 **이상하게 싼** 호텔·항공권만 골라서 보여주고, **왜 싼지**까지 추정해 주는 웹 앱.
아고다·호텔스닷컴·스카이스캐너를 하나하나 눌러보지 않고, "평소 대비 얼마나 튀는가" 하나만 본다.

> 현재 목록은 **샘플 데이터**(결정적 난수, 기준일 2026-09-24)로 동작합니다. 실제 판매가가 아닙니다.

## 실행

```bash
cd travel-deal-radar
npm start        # http://localhost:5173 (의존성 설치 불필요, Node 20+)
npm test         # 핵심 로직 단위 테스트
```

ES 모듈이라 `index.html`을 파일로 바로 열면 동작하지 않습니다. 반드시 `npm start`로 띄우세요.

## 판정 원리

1. **비교 대상 고르기**: 같은 호텔/노선의 과거 가격 중 *같은 날짜 유형*(평일·주말·연휴)이면서 *비슷한 시즌*(±45일)인 것만 쓴다.
   표본이 5개 미만이면 시즌 → 날짜 유형 순으로 조건을 풀고 신뢰도를 낮춘다.
2. **평소 가격 = 중앙값**. 평균이 아닌 중앙값이라 한두 번의 폭등/폭락에 흔들리지 않는다.
3. **할인율 = 1 − 현재가 / 평소가** → 등급
   | 등급 | 기준 |
   |---|---|
   | 🔥 역대급 | 40% 이상 |
   | 💎 아주 좋은 딜 | 25% 이상 |
   | 👍 좋은 딜 | 15% 이상 |
   | 😐 평소 수준 | −10% ~ 15% |
   | ⚠️ 비쌈 | 10% 넘게 비쌈 |

   15%/25% 기준은 Google Hotels의 Deal/Great deal 배지 기준과 맞췄다.
4. **왜 쌀까?** 규칙 기반 추정(`src/core/dealScore.js` `explainReasons`): 막판 재고 떨이, 명절 당일 역수요(가설), 취소 객실 풀림, 얼리버드, 평일 비수기, 환불불가 요금, 에러페어/가격 오류 가능성. 각 항목에 신뢰도(높음/중간/가설)를 붙인다.
5. 25% 이상 싸면 **예약 전 체크리스트**(확정 메일, 호텔 직접 확인, 최근 리뷰, 총액 등)를 같이 보여준다.

## 구조

```
index.html              화면 (정적, 빌드 없음)
src/core/calendar.js    날짜 유형(평일/주말/연휴) + 한국 공휴일
src/core/dealScore.js   베이스라인·등급·이유 추정 (UI와 분리, 테스트 대상)
src/data/sample.js      샘플 가격 이력 생성 → 실데이터 어댑터로 교체할 자리
src/ui/app.js           목록/필터/빠른 판정 폼
test/                   node:test 단위 테스트
```

## 실데이터로 가려면 (다음 단계)

핵심은 **가격 이력을 우리가 직접 쌓는 것**. 하루 1~2회 관심 호텔/노선 가격을 수집해 저장하면, 그 이력이 곧 "평소 가격"이 된다.

- 수집원은 **공식 제휴/API**를 우선: 항공(Duffel, Travelpayouts 등 제휴 API), 호텔(Agoda·Expedia 제휴 프로그램, 또는 Google Hotels 결과를 제공하는 SerpApi 같은 유료 API).
  Amadeus Self-Service API는 2026-07-17에 종료되어 사용할 수 없다.
- 예약사이트 **무단 크롤링은 약관 위반·차단 위험**이 있어 MVP 이후 설계에서 제외.
- 공휴일은 공공데이터포털 "특일 정보" API로 자동 갱신.
- 알림: 관심 목록에서 "좋은 딜" 이상이 뜨면 푸시/카카오 알림톡.
