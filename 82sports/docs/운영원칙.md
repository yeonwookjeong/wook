- 구호·홍보 문구 금지 ("놓치지 않으려면", "원문까지 정리합니다" 등). 확정 안 된 것은 만들지 않고 먼저 묻는다.

## 글
- 말투 B(가벼운 다체). 한 문장 한 생각, 결론 먼저, 번역투 금지, 임의 약어 금지.
- 외신·인물 인용은 원어 원문 + 굵은 번역 + 출처(기자·매체·날짜). 직접 확인한 원문만 따옴표, 재인용은 따옴표 없이.
- 검색용 글: [82 리포트]/[82 단신] 태그 + 검색어 + 날짜. 홈판용 글: 태그 없이 따옴표 훅 + 선수 + 전망 (docs/홈판제목패턴_v1.md).
- 홈판에서 뜨는 건 전망·주장 칼럼. 원고마다 '(여기에 본인 한 줄)' 자리 1~2곳, 총평은 직접 고쳐 쓰기.
- 붙여넣기는 글자만(모바일용 본문), 소제목·사진은 에디터에서 직접.
- 제외 선수: 황희찬, 양민혁, 박승수. 국내 무대 소식 제외.

## 사진

- 사용 가능: 선수·구단·연맹·대회 공식 인스타·홈페이지·Flickr. 출처 표기. Getty·AP 금지. 경기 영상 금지. 요청 오면 당일 삭제.
- 검수 15점 = 저작권·출처 5 + 사진 품질 10 (얼굴만 나온 프로필 사진은 0점).
