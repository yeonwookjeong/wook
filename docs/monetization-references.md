## 1. HeadshotPro — AI 비즈니스 프로필 사진

- **출처:** 스레드 게시물(대니 포스트마 사례 썰), 2026-11-02 확인
- **한 줄 모델:** 사진 몇 장 업로드 → AI가 링크드인용 프로필 사진 생성 → 이메일 발송
- **가격:** 약 29달러부터 (게시물 기준)
- **타깃:** 이직·취업이 걸린 직장인, 기업 채용팀 (재미용 사용자가 아님)
- **운영:** 결제(Stripe) → 생성 → 발송까지 자동, 고객 응대 최소화
- **유입:** 광고비 대신 **수수료 30% 제휴 프로그램** → 블로거·유튜버가 리뷰로 홍보
- **숫자**
  - 제휴로 월 5만 달러 이상, 월매출의 15% 이상 — 제휴 솔루션 회사(Rewardful) 사례 글 기준, **감사받은 숫자 아님**
  - 수수료 30% — 공식 제휴 페이지 표기 ✅
  - "월 4억 4천만 원 / 연 53억" — 게시물 주장, 위 비율로 역산하면 대략 맞는 범위, 공식 출처 없음
- **핵심 3가지**
  1. 같은 기술이라도 "재미"가 아니라 **절박한 순간(취업·이직)**에 붙이면 지갑이 열린다
  2. 결제부터 결과물 전달까지 **사람 손이 안 가는 구조**
  3. 제휴 수수료를 넉넉히 줘서 **남이 대신 홍보**하게 만든다
- **한국 적용 시 체크**
  - 공기업 블라인드 채용은 사진을 받지 않는 경우가 많음 → 민간 기업, 링크드인·리멤버 프로필 수요
  - 국내 AI 프로필 앱이 이미 많음 → 좁은 틈새(직군·용도)가 필요
- **링크:** [Rewardful 사례](https://www.rewardful.com/case-studies/headshotpro) · [공식 제휴 페이지](https://www.headshotpro.com/affiliate)

- **구조**
  - Blogger + 개인 도메인 (서버비 0원)
  - GitHub Actions가 4시간마다 잡알리오·나라일터·고용24 공고 수집 → GitHub Pages JSON → 카드 화면
  - GA4 조회수를 6시간마다 반영해 추천 순서 계산
  - 상세 글은 같은 틀에 값 채우기, 알리오 경영공시의 평균 연봉을 붙임
- **숫자:** 상세 글 1,345개 (2026-09-24 시작, 약 5주, 하루 35~40개), 글당 약 4,400자, **본문 광고 9칸 + 전면 광고**
- **배울 점:** 요약 카드, 표 위주 정리, 경영공시 연봉 붙이기, 마감 임박순 카드, 상단 고정 탭
- **피할 점:** 공고마다 자동 대량 발행, 광고 과밀, 반복 문구 → 검색 노출 소멸 위험 (아래 ⚠️ 사례)

- **한 줄 모델:** 스레드 주제별 시리즈 → 상황별 링크(`?t=job`) → 지원금 검색기(카드 4개마다 광고) → 자체 상세 글 또는 공식 사이트
- **구조**
  - 지원금 데이터는 외부("아로스", `abaeksite/allinone_lecture_skin`)에서 받아 씀 → 강의·스킨 판매자가 주는 데이터로 추정
  - 그 위에 직접 얹는 층: 데이터 보정, 직접 추가 카드, 카드별 후킹 2줄, 상황어 검색(자취·취준·첫월급), 고정 순위
  - 필터: 나이, 지역, 성별, 소상공인 여부
- **배울 점:** 상황어 검색, 스레드용 프리셋 링크, 후킹 2줄, 사람이 정하는 고정 순위
- **약점:** 외부 데이터 의존(보정 칸에 오류 정정이 많음), 같은 스킨을 쓰는 사이트가 많을 가능성, 근거 없는 "1인 평균 127만원" 문구

  - [ ] 값(기관명·날짜·금액)을 지워도 남는 고유한 내용이 있나?
  - [ ] 원문 공고나 공식 사이트보다 더 주는 정보가 하나 이상 있나?
  - [ ] 같은 틀의 다른 글과 문장이 절반 이상 겹치지 않나?
