# 작명 설계 (영어판 우선)

외국인에게 사주로 한국 이름을 지어 주는 기능. 영어판의 첫 상품.
흐름: 배경 콘텐츠 → 무료 이름 1개(화면) → 유료 리포트(후보 3개, 사주 근거, 서예, 도장, 이메일 발송).

## 1. 이론 결정 (확정)

| # | 항목 | 결정 |
|---|---|---|
| 1 | 한자 오행 기준 | **자원오행으로 용신 채우기** (`readChart`의 yong/hee). 없는 오행이 용신·희신이면 "없는 기운까지 채움"으로 덧붙임 |
| 2 | 이름 두 글자 | 용신 1 + 희신 1이 기본. 마땅치 않으면 하나는 중립. 기신·부담(burden) 오행 글자는 제외 |
| 3 | 성 | 오행 판단에서 제외. 획수·소리 계산에는 포함 |
| 4 | 발음오행 | 현행 작명소 방식(ㄱㅋ木 · ㄴㄷㄹㅌ火 · ㅇㅎ土 · ㅅㅈㅊ金 · ㅁㅂㅍ水). 배지로만 표시. 해례본과의 논쟁은 칼럼 소재 |
| 5 | 획수 | 원획법 (氵=水 4획, 阝(우)=邑 7획 등) |
| 6 | 81수리 | 후보 거를 때 원격·정격 흉수 제외. 화면 표시는 유료 리포트에서만 |
| 7 | 획수 음양 | 배지. 세 글자 전부 홀수 또는 전부 짝수면 제외 |
| 8 | 불용문자 | 쓰지 않음. 뜻이 나쁘거나 어색한 글자만 직접 제외 |
| 9 | 충돌 시 우선순위 | 자연스러움·뜻 > 용신 > 81수리 > 발음오행 > 음양 |
| 10 | 순우리말 이름 | 자원오행이 없으므로 **뜻으로 오행 연결** (예: 가람=水). 우리 방식임을 화면에 밝힘 |
| 11 | 외국인의 성 | 영어 성과 발음이 비슷한 한국 성 추천, 사용자가 변경 가능 |

## 2. 이름 종류 (사용자가 선택)

- **Hanja name** (기본·추천): 사주로 고른 한자. 서예·도장 상품과 연결
- **Pure Korean name**: 순우리말. 발음이 쉽고 뜻이 바로 와닿음. 공유용
- **Show me both**: 둘 다 보기
- 결과 화면에서 다른 종류로 바꿔 보기 가능

## 3. 나이 (세대 느낌)

생년월일로 나이를 이미 알고 있으므로 따로 묻지 않는다.
한국인은 이름에서 세대를 느낀다. 40대 외국인이 2010년대 아기 이름을 받으면 어색하다.

| 선택 | 내용 |
|---|---|
| **Fits my age** (기본) | 그 출생 연대에 자연스러운 이름 |
| **Timeless** | 세대를 크게 타지 않는 이름 |
| **Young & trendy** | 요즘 아이들 이름 느낌. 나이가 많으면 "한국인에겐 아주 어린 느낌" 안내 |

순우리말 이름에도 세대가 있다 (슬기·보람·나래·다솜 등은 1980~90년대 느낌).

출생 연대 구간: ~1974 / 1975–1989 / 1990–2004 / 2005~
자료: 대법원 출생신고 인기 이름 통계(최근 연도) + 한국인 검수자 판단(이전 연대). 연대별 예시 이름은 자료 확인 후 채운다.

## 4. 외국인 고려사항 → 기능

| 고려사항 | 반영 |
|---|---|
| 발음 난이도 (ㅓ/ㅗ, ㅡ, 된소리, 받침 ㄹ) | 어려운 소리는 점수 감점 |
| 로마자가 영어로 이상하게 읽힘 (Bum, Suck, Sin, Dong, Suk) | 금지 목록으로 제외 |
| 원래 이름과의 연결 | 입력: Similar sound / Similar meaning / Doesn't matter |
| 성별 느낌 | 입력: Masculine / Feminine / Neutral |
| 세대 느낌 | 3절 |
| 아이돌 이름과 겹침 | 겹치면 안내 |
| 진짜 한국 이름인지 | 출시 전 한국인 검수 (20~50대 섞어서 3~5명) |
| 뜻과 이야기 | 글자별 영어 뜻 + 한 줄 이야기 |
| 문신 용도 | 정확한 서예 이미지 제공 (유료) |

## 5. 결과 화면

```
Your Korean name: 하윤 (Ha-yun) · 夏允

How it sounds to Koreans
  · Modern and popular, especially for people born after 2010
  · Feels feminine, soft and bright
  · Easy for English speakers to say

Why this name   (사주 근거 한 줄)
✓ Balances your chart  ✓ Sound flows well  ✓ Yin-yang balanced

Say it: [▶ listen]   Write it: [stroke order]
```

"How it sounds to Koreans"가 다른 이름 생성기와의 가장 큰 차이다.
