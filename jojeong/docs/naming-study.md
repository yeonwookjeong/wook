# 훈도 작명 공부 노트

작명(이름 짓기) 기능과 이름 콘텐츠를 만들기 전에 찾아보는 기준집이에요. 명리 공부 노트(`myeongri-study.md`)와 같은 방식으로,
근거가 확실한 것만 적고 학파마다 갈리는 건 갈린다고 적어요. 설계 결정은 `naming.md`에 있어요.

표시: ✅ 정설(대부분 같은 말) · ⚖️ 학파마다 다름 · ⚠️ 우리가 틀렸던 것 · 🔶 우리만의 방식(화면에 밝힘)

---

## 1. 법과 제도

| 항목 | 기준 | 표시 |
|---|---|---|
| 인명용 한자 | 출생신고 때 이름에는 대법원이 정한 인명용 한자만 쓸 수 있어요. 지금 **9,389자** (2024년 6월 11일 시행, 8,319자에서 1,070자 늘어남) | ✅ |
| 한글 이름 | 한자 없이 한글로만 등록할 수 있어요 | ✅ |
| 성 표기와 두음법칙 | 李는 '이', 柳는 '유'가 기본이지만, 2007년 대법원이 '류·리·라' 등 원래 소리로 적는 것도 허용했어요 | ✅ |
| 외국인 귀화 | 귀화하면 한국식 성과 본을 새로 만들 수 있어요 (성·본 창설) | ✅ |
| 외국인의 "한국 이름" | 귀화하지 않은 외국인에게는 법적 효력이 없어요. 별칭·예명이에요. 화면에서도 그렇게 말해요 | ✅ |

## 2. 자원오행 (字源五行) — 우리 작명의 핵심

| 항목 | 기준 | 표시 |
|---|---|---|
| 정하는 법 | 글자의 부수(뿌리 글자)로 오행을 정해요. 木·禾·竹 계열은 木, 火·灬는 火, 土·山·田은 土, 金·石은 金, 水·氵·雨는 水 | ✅ |
| 부수로 안 정해지는 글자 | 日·月·玉·心 같은 부수, 부수와 뜻이 다른 글자는 작명 사전마다 다르게 적어요. 예: 日을 火로 보는 사전이 많지만 다른 기준도 있어요 | ⚖️ |
| 쓰는 법 | 사주에 필요한 기운(용신·희신)을 이름 글자로 채워요 | ⚖️ (아래) |
| 두 가지 흐름 | **용신 채우기**: 사주 균형에 필요한 기운을 채움 (우리 방식) · **없는 오행 채우기**: 사주에 0인 오행을 채움 (작명소에서 흔함). 둘의 답이 다를 때가 많아요 | ⚖️ |
| 성 | 성은 고를 수 없어서 오행 판단에서 빼는 곳이 많아요 | ⚖️ |
| 데이터 | 공개 표준 데이터가 없어요. 작명 사전 2~3개를 대조하고, 엇갈리는 글자는 `disputed`로 표시해요 | — |

## 3. 발음오행 (소리오행)

이름 첫소리(초성)의 오행이에요. 성 → 이름 첫 글자 → 끝 글자가 서로 살려 주는 순서(상생)면 좋다고 봐요.

| 소리 | 훈민정음운해 (신경준, 1750) · 지금 작명소 다수 | 훈민정음해례 (1446, 1940 발견) |
|---|---|---|
| ㄱㅋ (어금닛소리) | 木 | 木 |
| ㄴㄷㄹㅌ (혓소리) | 火 | 火 |
| ㅅㅈㅊ (잇소리) | 金 | 金 |
| ㅇㅎ (목구멍소리) | **土** | **水** |
| ㅁㅂㅍ (입술소리) | **水** | **土** |

| 항목 | 기준 | 표시 |
|---|---|---|
| 어느 쪽을 쓰나 | 작명 실무는 운해본이 다수설이에요. 학계에는 한글 창제 원전인 해례본이 맞다는 연구가 있어요 (이재승·김만태, 2018) | ⚖️ |
| 방법 자체에 대한 비판 | 발음오행 작명법이 훈민정음 원리나 음운 법칙과 맞지 않는다는 연구도 있어요 | ⚖️ |
| 우리 | 운해본 기준으로 배지만 보여 줘요. 한국 사용자가 다른 작명 앱으로 확인해도 같게 나오게요. 두 기준이 모두 상생이면 그렇게 말해요 | 🔶 |

## 4. 수리 (획수)

| 항목 | 기준 | 표시 |
|---|---|---|
| 원획법 | 부수를 원래 글자의 획수로 세요. 氵=水 4 · 扌=手 4 · 忄=心 4 · 犭=犬 4 · 礻=示 5 · 衤=衣 6 · 艹=艸 6 · 王(구슬옥변)=玉 5 · 月(육달월)=肉 6 · 辶=辵 7 · 왼쪽 阝=阜 8 · 오른쪽 阝=邑 7 | ✅ (작명계 표준) |
| 숫자 글자 | 四·五·六·七·八·九·十을 획수 대신 숫자 값(4~10)으로 세는 학파가 있어요 | ⚖️ |
| 4격 (원형이정) | 원격 = 이름 두 글자 합 · 형격 = 성 + 이름 첫 글자 · 이격 = 성 + 이름 끝 글자 · 정격 = 전체 합 | ✅ (한국식) |
| 외자 이름·두 글자 성 | 4격 계산법이 학파마다 달라요 | ⚖️ |
| 81수 길흉 | 1~81 수마다 길흉을 정한 표예요. 81을 넘으면 80을 빼고 봐요. 표마다 몇몇 수의 길흉이 달라요 | ⚖️ |
| 기원 | 지금의 획수 성명학 틀(五格)은 일본의 구마사키 겐오(熊崎健翁, 1881~1961)가 만들었고, 한국의 4격은 그 변형이라는 견해가 있어요. 氵를 4획으로 세는 원획법도 이 계열의 특징이에요. 중국 송나라 채침에서 왔다는 말은 근거를 확인하지 못했어요 | ⚖️ |
| 우리 | 원격·정격이 흉수인 조합만 걸러요. 화면 표시는 유료 리포트에서만 | 🔶 |

## 5. 음양 (획수 홀짝)

| 항목 | 기준 | 표시 |
|---|---|---|
| 정하는 법 | 획수가 홀수면 양, 짝수면 음 | ✅ |
| 좋은 배열 | 음과 양이 섞이면 좋고, 전부 음이거나 전부 양이면 피해요 | ✅ |

## 6. 불용문자

| 항목 | 기준 | 표시 |
|---|---|---|
| 내용 | 이름에 쓰면 안 좋다는 글자 목록 (예: 龍·鳳·花 등) | ⚖️ |
| 우리 | 작명소마다 목록이 달라서 쓰지 않아요. 뜻이 나쁘거나 어색한 글자만 직접 빼요 | 🔶 |

## 7. 이름 관습

| 항목 | 기준 | 표시 |
|---|---|---|
| 구성 | 성 1글자 + 이름 2글자가 대부분. 외자(이름 1글자)와 두 글자 성(남궁·제갈·선우 등)도 있어요 | ✅ |
| 항렬자 (돌림자) | 같은 세대가 이름 한 글자를 함께 써요. 집안(본관)마다 정해져 있어요 | ✅ |
| 세대 느낌 | 이름만 들어도 대략 몇 년대생인지 느껴져요. 최근 연도는 대법원 출생신고 인기 이름 통계로 확인하고, 그 이전은 검수자 판단으로 보완해요 | ✅ |
| 성별 느낌 | 끝 글자로 성별 느낌이 갈리는 이름이 많아요. 중성적인 이름도 늘고 있어요 | ✅ |

## 8. 로마자 표기

| 항목 | 기준 | 표시 |
|---|---|---|
| 기준 | 국어의 로마자 표기법 (2000). 성과 이름은 띄어 쓰고, 이름은 붙여 쓰는 게 원칙이며 음절 사이 붙임표(-)도 허용해요. 예: 한복남 Han Boknam (Han Bok-nam) | ✅ |
| 이름 안의 소리 변화 | 이름 안에서 일어나는 소리 변화는 표기에 반영하지 않아요. 예: 홍빛나 Hong Bitna | ✅ |
| 성 표기 | 성은 관용 표기(Kim, Lee, Park)를 많이 써요 | ✅ |
| 외국인용 주의 | 영어로 이상하게 읽히는 표기(Bum, Suck, Sin, Dong, Suk 등)는 후보에서 빼요 | 🔶 |

| 항목 | 기준 | 표시 |

## 11. 가져온 자료와 우리 기준 (2026-10-19)

**배울지 말지의 기준**
1. 라이선스: MIT·Unicode 같은 공개 라이선스만 데이터나 코드를 가져와요. 라이선스가 없으면 **방법만 배우고** 코드·데이터는 가져오지 않아요.
2. 원천: 대법원·Unicode 같은 1차 자료를 우선해요. 남이 정리한 값은 1차 자료와 대조한 뒤에만 써요.
3. 우리 이론과 맞나: 원획법·4격·용신 채우기(1~5장)와 다른 셈법은 쓰지 않아요.
4. 갈리면 빼요: 학파마다 다른 값은 추천에 쓰지 않고 `미정`으로 둬요.
