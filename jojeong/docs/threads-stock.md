# 스레드 원고 창고

승인된 원고와 승인 대기 원고를 모아 두는 곳입니다. 사이트에는 들어가지 않습니다.

- 상태: ✅ 승인 · ⏳ 대기 · 📤 올림 (날짜와 24시간 숫자 기록)
- 원칙
  - 첫 줄은 용어가 아니라 사람들이 실제로 듣는 말로 엽니다.
  - 1편에 본론(누구 이야기인지)이 다 들어갑니다.
  - 용어와 근거는 2편으로 넘깁니다.
  - 2편 끝에 "주변에 ○○ 있으면 보여 주시옵소서"로 태그를 부릅니다.
  - 참고 자료에서는 왜 되는지만 가져오고, 문장은 우리 것으로 씁니다.
- 기록할 숫자: 24시간 조회 · 좋아요 · 댓글 · 태그 수

## 시기가 있는 글 (먼저)

### 1. 토끼띠 10월 ⏳ · 10/7까지
근거: 10/8 한로부터 戌월, 卯戌 육합

**1/2**
```
<63·75·87·99년생 토끼띠>

10월 8일부터 한 달,
마음이 묶이는 사람이 생기옵니다.

다만 한번 묶이면 쉽게 안 풀리는 달이지요.
```
**2/2**
```
토끼와 개는 사주에서 짝이옵니다.
묘술합(卯戌合)이라 하여 서로 끌어당겨 묶이지요.

10월 8일부터는 개의 달.
그대 띠가 한 달 내내 짝을 만나는 셈이옵니다.

사람도, 일도, 약속도 묶이는 쪽으로 흐르니
아무 손이나 잡지 마시고, 골라서 잡으시옵소서.

주변에 토끼띠 있으면 보여 주시옵소서.

더 깊은 이야기는 그대 사주에 있사옵니다
프로필 링크로 오시옵소서
```

주변에 용띠 있으면 보여 주시옵소서.

## "○○ 소리 듣는 일주" 시리즈
근거: 태어난 날 아래 글자(일지)의 본기 십성. 60일주 중 해당 일주를 코드로 대조함.

### 3. 기가 세다 · 괴강 ✅
**1/2**
```
사주만 봐도 "기가 세다" 소리를 듣는 일주가 있사옵니다.

경진 · 경술 · 임진 · 임술 · 무술

이 일주들은
한번 정하면 끝까지 밀어붙이고
남 밑에 오래 있으면 답답해하고
판이 흔들릴수록 오히려 침착해지옵니다.

그대는 다섯 중 하나이옵니까?
```
**2/2**
```
옛 명리학은 이 다섯을 '괴강(魁罡)'이라 불렀사옵니다.
하늘의 두 별, 천강과 하괴에서 따온 이름이지요.

옛사람들은 괴강을 '극과 극'이라 했사옵니다.
잘 풀리면 크게 풀리고, 막히면 크게 막히지요.
그래서 이 일주에게 제일 어려운 말이 '적당히'이옵니다.

주변에 고집은 센데 이상하게 믿음 가는 사람,
그 사람 일주를 한번 보시옵소서.

여기 그대 일주가 없사옵니까?
프로필 링크로 오시옵소서
```

주변에 말로 못 이기는 사람 있으면 보여 주시옵소서.

## 체크리스트 시리즈

### 10. 역마 ✅ (첫 줄 다듬음)
**1/2**
```
"너는 왜 이렇게 가만히를 못 있어?" 소리 들어 봤다면
하나씩 세어 보시옵소서.

1. 집에만 있으면 이틀 만에 답답해진다
2. 여행은 가는 날보다 계획 짜는 날이 더 신난다
3. 이사·이직 얘기만 나오면 마음이 먼저 가 있다
4. 단골보다 처음 가 보는 가게가 끌린다
5. 낯선 동네에서도 금방 길을 익힌다
6. 사무실에 앉아 있는 것보다 밖에 돌아다니는 일이 편하다
7. 한곳에 3년쯤 있으면 뭐라도 바꾸고 싶어진다

셋 이상이면 그대 사주엔 역마가 있을 확률이 높사옵니다.
```
**2/2**
```
역마는 '떠돌이 팔자'가 아니옵니다.
움직여야 일이 풀리는 사람이라는 뜻이지요.
가만히 묶어 두면 오히려 탈이 나옵니다.

사주표 아래 줄에
인(寅)·신(申)·사(巳)·해(亥) 가운데 하나라도 있으면, 그게 역마.

어느 칸에 있느냐로 움직이는 방향이 다르옵니다.
연주 : 어릴 때 이사·전학이 잦았던 사람
월주 : 출장·외근·해외 일이 붙는 사람
일주 : 같이 떠날 수 있는 사람과 잘 맞는 사람
시주 : 나이 들수록 멀리 가고 싶어지는 사람

더 깊은 이야기는 그대 사주에 있사옵니다
프로필 링크로 오시옵소서
```
