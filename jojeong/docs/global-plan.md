# 해외판 계획 (대표님 확정 2026-11-09)

## 순서
영어(유입) → 일본어(매출) → 스페인어(놀이) → 번체 중국어(대만, 2027 신년운세를 춘절 전에)

## 원칙
- 엔진은 하나, 언어별로 화면 문구, AI 보고서 지침, 약관과 개인정보, 공유 카드, 칼럼을 그 언어로 새로 쓴다(번역만 하지 않는다).
- 사주는 "Saju (Korean Four Pillars)", 조선 관상감 훈도 정가를 앞세워 중국식 팔자와 다르게 보이게 한다.
- 생년월일은 저장하지 않는다(해외 개인정보 규정에도 유리).
- 애드센스용으로 한국어 글을 기계 번역해 늘리지 않는다(가치 없이 대량으로 만든 페이지로 볼 위험).

## 서비스 (언어마다 같은 짝)
| 서비스 | 무료/유료 | 간판 시장 |
|---|---|---|
| 무료 사주 풀이(정체 카드, 다섯 기운, 지나온 해) | 무료 | 전체 |
| 조선 신분 놀이 | 무료 | 스페인어 |
| 한국 이름 짓기(작명) | 유료 | 스페인어, 영어 |
| 궁합 | 점수 무료, 풀이 유료 | 전체 |
| 평생 사주 AI 보고서 | 유료 | 일본어 |
| 2027 신년운세 | 유료 | 번체 중국어 |

## 결제
- 1단계: 토스페이먼츠 해외결제(해외 카드, 페이팔). 대표님이 신청 확인(11/9).
  - 페이팔: 4.0% + 건당 0.3달러, 환전과 인출 2.5% 별도, 부가세 10% 별도, 원화 정산, 취소해도 수수료 반환 없음(토스 이용요금 페이지, 11/9 확인).
  - 해외 카드 요율: 토스 문의 필요.
- 나중: 해외 매출이 커지면 판매 대행(MoR, 예: Paddle)으로 나라별 세금 신고를 맡기는 것 검토. 한국 사업자 정산 가능 여부 확인 필요.
- 해외 매출 전 세무사 확인: 일본, 대만, 유럽 등 디지털 상품 소비세 등록 기준.
- 같이 준비: 달러 가격, 언어별 환불 규정, 보고서 1편당 AI 원가, 결제 취소 분쟁(차지백) 대비 고지.

## 12주 로드맵
| 주 | 할 일 |
|---|---|
| 1~2 | 영어 무료판(무료 풀이 + 조선 신분), 출생 도시 입력, 영어 약관, 영어 작명 머지, 토스 해외결제 신청 |
| 3~4 | 영어 유료(평생 보고서, 작명, 궁합), 해외 카드 결제 연결, 영어 칼럼 5편 |
| 5~6 | 일본어판(문구 원고 docs/global-free-copy.md), 일본어 AI 지침 |
| 7~8 | 스페인어판(놀이와 작명 중심) |
| 9~10 | 번체 중국어판(2027 신년운세 춘절 전) |
| 11~12 | 판매 대행 검토, 언어별 숫자로 집중할 시장 결정 |

같은 기간 국내: 애드센스 재신청(60일주 도감, 미달 칼럼, 도구 설명 글), 전자책, 토스 미니앱(내 사주 명당).
