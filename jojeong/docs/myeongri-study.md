콘텐츠를 쓰기 전에 찾아보는 기준집이에요. 근거가 확실한 것만 적고, 학파마다 갈리는 건 갈린다고 적어요.

## 2. 합·충·형·파·해

| 짝 | 정확한 관계 | 쓸 때 주의 | 표시 |
|---|---|---|---|
| 사(巳)–신(申) | 육합이면서 형(刑) | "손잡는 짝"으로만 쓰지 않아요 | ✅ |
| 인(寅)–해(亥) | 육합이면서 파(破) | 합과 깨짐을 같이 말해요 | ✅ |
| 인(寅)–신(申) | 충 | 기계적으로 나쁘다고 하지 않아요. 이동·전환으로 읽어요 | ✅ |
| 축(丑)·술(戌)·미(未) | 셋이 모이면 삼형 | 2027 정미년에 축·술이 있는 사주는 삼형이 완성돼요 | ✅ |
| 반합 | 왕지(자·오·묘·유)가 낀 반합만 힘이 있다고 보는 쪽이 많아요. 삼명통회는 더 엄격해서 "셋 중 하나만 빠져도 국(局)을 이루지 못한다(三字缺一則化不成局)"고 적었어요 | 왕지 없는 반합을 "손잡는 날"로 쓰지 않아요. 반합도 "기운이 모이려는 정도"로 약하게 써요 | ⚖️ |
| 천간합 | 갑기·을경·병신·정임·무계 | 합이 됐다고 바로 그 오행으로 "변한다"(합화)고 하지 않아요. 적천수천미: "합해도 변하지 않는 경우가 있다(雖合不化)" | ✅ |

## 3. 신살 찾는 법

| 신살 | 기준 | 표시 |
|---|---|---|
| 도화·역마·화개 | 해(연지) 또는 날(일지)의 아래 글자로 삼합을 잡아 찾아요. 도화의 원래 이름은 함지(咸池)로, 삼합의 목욕 자리(인오술→묘, 사유축→오, 신자진→유, 해묘미→자)예요 (삼명통회 권2) | ✅ |
| 천을귀인 | 날의 위 글자(일간) 기준. 갑·무·경→축미, 을·기→자신, 병·정→해유, 임·계→사묘, 신→인오 (삼명통회 권3, 우리 엔진과 같음). 경(庚)을 인오로 보는 판본("갑무겸우양, 경신봉마호")도 있어요. 진·술에는 귀인이 오지 않아요 | ✅ (판본 차이 ⚖️) |
| 괴강 | 원전 기준은 **임진·경술·무술·경진 넷**이에요 (연해자평 「논괴강」, 삼명통회 권4, 신봉통고). 삼명통회는 임술을 괴강이 아닌 보통 날로 분류했어요. 임술을 넣는 건 후대 관법이에요. 우리 엔진도 원전 넷으로 맞췄어요 (2026-10-19). 콘텐츠에 "괴강 다섯"이라고 쓰지 않아요 | ⚠️ (예전 노트는 반대로 적었음) |
| 백호 | 갑진·을미·병술·정축·무진·임술·계축 일곱. 다만 연해자평·삼명통회·신봉통고에서 이 일곱 간지 목록은 찾지 못했어요. 옛 책의 백호(白虎)는 해의 흐름으로 잡는 다른 신살이에요. 후대(근현대) 관법으로 소개해요 | ⚖️ |
| 양인 | 양간만 보는 쪽(갑→묘, 병·무→오, 경→유, 임→자)이 일반적이에요. 연해자평: "녹 앞의 한 자리(祿前一位)". 삼명통회는 "자평은 다섯 양간만 양인이 있고 음간은 없다"고 적으면서, 열 간 모두 녹 앞 자리로 잡는 설(을→진, 정·기→미, 신→술, 계→축)도 함께 실었어요 | ⚖️ |
| 신살 해석 | 옛 책의 흉한 뜻을 그대로 옮기지 않아요. 지금 시대의 쓰임으로 풀어요 (예: 역마 = 움직여야 풀리는 사람) | ✅ |
