# 훈도사주 손님 시점 점검 (2026-10-14)

실제 배포(https://www.hundosaju.com)를 아이폰 폭(390px)·작은 폰(320px)·PC(1280px)에서 직접 돌았다. 생년월일 입력 → 무료 풀이 → 보고서 → 결제창 → 묻기 → 공유 → 왕이 될 사주 → 약관까지 전부 눌러 봤고, 결제는 토스 결제창이 뜨는 것까지만 확인했다. 캡처는 세션 스크래치 폴더 `ux/shots/`에 있다.

## 좋은 점 (지킬 것)

- 세계관이 끝까지 간다. 한지·인장·두루마리, 사극체, 정 훈도 캐릭터가 홈부터 404 페이지까지 한 톤이다.
- 무료 결과가 후하다. 사주표(십성·지장간·12운성·신살), "100명 중 n명", 성향 지도, 신살, 10년 흐름, 2027 한눈까지 한 페이지. 재훈은 "포스텔러보다 자세하다"고 느낀다.
- 태어난 시각 자유 입력 + 즉시 되짚기("오전 9시 30분으로 알아들었어요. 부산 경도 −24분 → 실제 09:06, 사시")와 도시 검색(뉴욕 서머타임 −60분까지)은 다른 서비스에 없는 강점이다.
- 공유 받는 쪽 화면이 좋다. "수진이 보내왔어요" 카드 → 바로 아래 내 생일 입력 폼. 카톡 미리보기 이미지(일주·한 줄 물상)도 예쁘다.
- 법적 고지가 충실하다. 청약철회 제한 문구가 결제 버튼 바로 아래, 생년월일 미저장 문구가 폼마다 있다. 환불·개인정보 페이지도 구체적이다.
- 메뉴(≡)는 details/summary라 키보드로도 열린다. 폼 레이블 연결, 랜드마크 등 접근성 기본은 갖춰져 있다. 자동 검사(axe) 위반은 2종뿐.
- 속도 기본은 좋다. 보고서 페이지 첫 응답 0.2초, 홈 0.46초.

## 고칠 점 (중요한 순)

### 1. 결제 직전에 믿음이 끊긴다 (성민)
- 결제 버튼을 누르면 사이트를 떠나 토스 결제창 전체 페이지로 간다. 첫 화면은 "신용/체크카드 · 간편결제" 목록뿐이고 상품명·금액·판매자가 안 보인다. 성민은 "내가 뭘 얼마에 사는 거지" 하고 뒤로 간다.
- 로그인·이메일 없이 결제된다. 산 보고서는 이 브라우저 쿠키(1년)에만 남고, `/my`는 "링크를 잃어버렸다면 문의하기"라고만 한다. 결제 버튼 근처에 "카카오로 로그인하면 어느 기기에서든 열려요"가 없다(메뉴 안에만 있음).
- 평생 사주 페이지는 무료 풀이 전체를 다시 보여 준 뒤에야 목차·가격이 나온다. 결제 버튼까지 약 8화면(13,000px)을 내려야 한다. 무료 풀이를 이미 본 사람에게는 중복이다.
- 환불 규정의 "한 번도 열람하지 않은 경우 7일 이내 전액 환불"은 결제 즉시 자동으로 열리는 구조라 실제로 해당될 수 없다. 분쟁 때 불리하게 읽힐 수 있다.

### 2. 2026년 잔재가 여섯 군데 (유진·혜정 모두 헷갈림)
홈은 "내 사주 · 2027"을 밀면서 아래 곳들은 2026을 가리킨다.
- 홈 og:description과 OG 이미지 문구 "평생 사주 · 궁합 · 2026 운세" (카톡에 홈 링크를 보내면 이게 보임)
- `/about` "2026 신년 운세"
- `/ranking` "내 사주 전체로 보는 2026년, 달마다"
- `/reports/sinbun` "2026 운세 (무료)"
- `/court/[id]` "신분 감정·2026 운세는 무료", "병오년 운세 '길' · 무료로 전부 공개"
- `/samjae` "여덟 글자로 보는 내 2026년 운세" (2027 미리 보기 링크는 있음)
- 홈 바로가기에 "내 사주 · 2027"과 "2026 삼재"가 나란히 있다.
- 궁합 결과 "2026 함께 좋은 해", 연애 10년 달력이 2026부터 시작. 10월 중순이면 2027부터가 자연스럽다.

### 3. 입력 오류 안내 (혜정)
- 2026년생을 넣으면 "1920년부터 2025년 사이로 입력해 주시옵소서". 올해 태어난 아이 사주를 보려는 부모가 막힌다. 상한을 오늘 날짜로.
- 오류 문구 말투가 섞여 있다. 폼은 해요체("알아들었어요")인데 오류만 사극체("존재하지 않는 날짜이옵니다", "해당 윤달이 없사옵니다").
- 시각을 잘못 넣으면 같은 뜻의 오류가 두 번 나온다(시각 칸 아래 "시각을 알아보지 못했어요…" + 성별 아래 "태어난 시각을 알아보지 못했사옵니다…").
- 날짜 오류가 생년월일 칸이 아니라 성별 칸 아래에 뜬다. 긴 폼에서 어디가 틀렸는지 눈이 헤맨다.
- 이름을 비우고 누르면 브라우저 기본 말풍선("Please fill out this field")이 영어로 뜨는 환경이 있다.

### 4. 공유 문구가 밋밋하다 (민지·유진)
- "친구에게 보내기 → 요약 한 장만"을 누르면 공유 시트에 들어가는 글이 "훈도사주 · 조선 관상감 훈도가 풀어 주는 무료 사주 + 링크"뿐이다. "수진은 임인일주, 표현하는 힘 70% · 같은 일주 중 8%"처럼 결과 한 줄이 들어가야 단톡방에서 눌린다.
- 받는 쪽 화면은 좋으니 보내는 글만 고치면 된다.

### 5. 방문 통계가 안 잡히고 있을 수 있다 (기술)
- 모든 페이지에서 `/294496bf162f3184/script.js`가 404다. 이 스크립트는 `@vercel/analytics/next`(data-sdkn)가 넣는 것이다. Vercel 프로젝트에서 Web Analytics가 꺼져 있거나 경로가 어긋난 상태로 보인다. 대시보드에 방문 수가 찍히는지 확인 필요.
- `hundo-shock.png`를 preload하는데 쓰지 않아 경고가 난다(작은 낭비).

### 6. 글씨 크기와 대비 (혜정·접근성)
- 9~11px 글자가 많다. 연운 달력 꼬리표("귀인", "인연·약속") 9px, 사주표 설명("자녀·말년", "을 · 목") 10px, 절기 날짜("2/4~") 10px. 홈에서 13px 이하 글자가 전체의 절반이다.
- 남색 바탕 금색 글자(三災, 身分, "1위")가 대비 기준 미달로 7건 잡혔다.
- 320px 폰에서 홈 "지금까지 1,352건"이 "1,35 / 2"로 줄바꿈된다(숫자 안에서 끊김).

### 7. 처음 보는 사람이 멈칫하는 표기 (재훈·유진)
- 연운 달력의 "2/4~, 3/6~"는 절기 날짜인데 분수처럼 보인다. "2월 4일~"가 안전하다.
- 2027 한눈 막대 아래 "힘이 붙는 달 10/8 · 11/7부터 |쉬어 갈 달 5/6 · 6/6부터"의 세로줄.
- 무료 결과의 "그래서 수진님은"이 약점 두 문장만 있다("마무리가 약해요", "구설이 생기기 쉬워요"). 들킴 효과는 있지만 첫 인상이 부정 일변도다. 강점 한 줄 + 약점 한 줄이 공유도 잘 된다.
- 묻기 페이지 예시 답서 날짜가 "10월 12일 12:00 / 丙午年 十月 十二日"로 고정이다. 한 달 뒤엔 오래된 느낌이 난다.

### 8. 첫 화면 팝업 (유진)
- 첫 방문에 "정식으로 문을 열었습니다" 팝업이 홈 전체를 덮는다(1회만 뜨긴 함). 릴스에서 들어온 유진은 "내 사주 무료로 보기"를 보기 전에 ✕부터 찾는다.
- 팝업 버튼이 "청심당 가서 첫 질문 받기"다. 입구에서는 조선 이름을 안 쓰기로 한 규칙과 어긋난다("정 훈도에게 묻기"로).

### 9. 자잘한 것
- 404 페이지 제목(title)이 홈 제목 그대로다. "페이지를 찾을 수 없어요 · 훈도사주"로.
- 잘못된 보고서 링크(`/r/없는값`)를 열면 아무 말 없이 `/my`로 간다. "링크가 만료됐거나 잘못됐어요" 한 줄이 필요하다.
- PC에서는 가운데 모바일 폭 한 줄만 있고 양옆이 빈 한지다. 칼럼은 검색 유입이라 PC 비율이 있을 수 있다. 칼럼 페이지만이라도 본문 폭을 넓히면 좋다.
- 홈 첫 로드가 1.9MB다(웹폰트 woff2 20여 개 + Pretendard CDN 동적 서브셋 + 카드 이미지 2장). 보고서 페이지는 50KB라 홈만 무겁다.
- 고객센터가 gmail 주소다. 카드사 심사 중이라 지금은 손대지 않되, 끝나면 도메인 메일로.
