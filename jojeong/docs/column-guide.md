# 칼럼 쓰는 기준 (2026-10-28~)

애드센스가 10/28 "가치가 별로 없는 콘텐츠"로 거절했다. AI로 썼다는 것 자체는 거절 사유가 아니다. 구글이 막는 것은 **가치를 더하지 않는 페이지를 대량으로 만드는 것**이다(Google Search Central, 생성형 AI 콘텐츠 안내). 그래서 새 칼럼은 "다른 사이트에 없는 것"이 들어가야 낸다. 이미 나간 칼럼은 그대로 두고, 새로 내는 것부터 이 기준을 따른다(대표님 10/28).

## 한 편이 갖춰야 할 것

| 항목 | 기준 |
|---|---|
| 우리만 가진 것 | 아래 셋 중 **하나 이상** 필수. ① 훈도사주 엔진 숫자(1950~2008년 모든 날 × 12시, 사주 258,600개 셈. `lib/sinsalRarity.json`, `lib/rarity.ts` 등) ② 원문 대조(책·권·편 + 한자 + 한글 읽기) ③ 실제 손님 질문·댓글에서 나온 물음(이름·생일은 빼고) |
| 분량 | 본문 한글 **2,000자 이상**. 늘리려고 같은 말을 되풀이하지 않는다 |
| 표·그림 | 한 편에 표 하나 이상(숫자 표, 원문 대조 표, 비교 표) |
| 출처 | 옛 책 인용은 책·편명과 한글 풀이를 붙인다. 확인 못 한 구절은 쓰지 않는다 |
| 단정 | 학파마다 다른 풀이는 "보는 관법이 있다", "책마다 다르다"로. 무섭게 쓰지 않는다 |
| 글쓴이 | 끝에 "정 훈도 · 계산은 훈도사주 엔진, 원문은 ○○ 대조" 한 줄 |
| 대표님 한 줄 | 가능하면 대표님 경험 한 줄(상담·댓글에서 본 것)을 받아 넣는다. AI가 대신 못 쓰는 부분 |
| 이어지는 곳 | 마지막에 관련 무료 화면(신살 유형 테스트, 삼재, 랭킹 등) 한 곳으로 연결 |

## 쓰지 않는 것

- "○○이란 무엇인가"로 시작해 개념만 설명하고 끝나는 글
- 어디서나 볼 수 있는 성격 나열("리더십이 있고, 고집이 세며…")
- 같은 틀에 단어만 바꾼 글을 여러 편 한꺼번에
- 출처 없는 숫자, 지어낸 사례·후기

## 내는 속도

- 하루 한 편 이하. 칼럼마다 `date`가 있어 그날 0시에 열린다(`publishedColumns()`), 미리 머지해도 한꺼번에 나가지 않는다.
- 같은 날 스레드 점심 글과 주제를 맞춘다(스레드 → 칼럼으로 이어지게).

## 내기 전 점검

1. 위 "우리만 가진 것"이 어디에 있는지 한 줄로 적을 수 있는가
2. 숫자는 사이트 화면과 같은가(반올림 포함)
3. 한자 옆에 한글이 있는가
4. 2,000자 이상인가
5. 같은 주제를 최근 2주 안에 다루지 않았는가

애드센스 재신청은 이 기준으로 쓴 칼럼이 쌓이고, 도구 페이지에 설명 글을 붙인 뒤(11월 중순 예정) 한다.
