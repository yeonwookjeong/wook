# 훈도사주 로드맵 (2026-11-20 대표님 방향)

> 한국: 결제할 수 있는 손님에게 전력. 외국: 콘텐츠와 놀이로 모으고 애드센스로 번다.
> 상품, 전자책, 콘텐츠, 무료 놀이를 계속 늘려 사이트를 키우고, 그다음 더 큰 플랫폼으로.

## 1단계: 지금 ~ 12월 (한국 매출 기반)
| 줄기 | 할 일 | 상태 |
|---|---|---|
| 콘텐츠 | 스레드 하루 5편, X 한 트윗 + 이미지, 칼럼 매일 | 진행. 기준: 첫 줄은 읽는 이 이야기, 1~3단 한 흐름, 동물의 달은 날짜 없이, 비율 글은 하루 하나 |
| 무료 놀이 | 벼슬길(/byeoseul, 숨김) 출시, 나와 같은 일주 유명인(/star, 숨김) 출시, 60일주 도감 입구 | 대표님 폰 시험 대기 |
| 상품 | 놀이 결과마다 유료 연결 하나(유명인 → 궁합, 호패 → 평생 사주 등), 2027 신년운세 성수기(12~2월) 묶음 | 기획 |
| 전자책 | 1권 『내 사주, 내가 제일 잘 안다』 가이드북, 해요체, 하루 2장, 쓰는 즉시 docs/ebook/에 push | 1장 초안 |
| 외국 | /en, /ja에 광고 자리. 결제는 보류(아래) | 다음 |

## 2단계: 1~3월 (확장)
- 무료 놀이를 한 달 1개 이상. 공유되는 놀이(친구 넣기, 순위, 카드)를 우선.
- 외국: 영어판 K-pop 일주 쌍둥이(유명인 놀이), 영어판 호패, 영어 칼럼으로 검색 유입, 애드센스.
- 상품: 전자책 1권 판매(사이트 기본, 크몽 보조), 2권 기획.

## 3단계: 더 큰 플랫폼
- 세부 기획 문서 없음. 대표님 구상을 받아 hundo-newbiz가 사업 기획 1장으로 쓴다(docs/team.md).
- 들어갈 근거: 무료 놀이 월 이용자, 카카오 가입자 수, 재구매율.

## 해외 결제 (11/20 토스 상담 결과)
| 수단 | 조건 | 결정 |
|---|---|---|
| 해외카드 4.5%, 원화 | 객단가 1만 원 이상. 지금 상점은 1만 원 미만 상품이 있어 불가 | 보류 |
| 페이팔 4.4% + 환전 2.134% + 건당 0.33달러 | 상점(MID) 분리, 가입비 22만 원 + 연회비 11만 원(면제 불가, 먼저 결제해야 심사) | 보류. 첫해 33만 원을 페이팔 순수익으로 메우려면 1만 원짜리 약 36건 이상 |
| 지금 상점 | 퀵오픈(가입비, 연회비 1회 면제) | 유지 |
- 해외 방문자와 광고 수익이 쌓이면 다시 본다.
- 삼성카드 미신청은 대표님이 일부러 미룸. 다시 꺼내지 않는다.
