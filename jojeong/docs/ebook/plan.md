## 기획 의도 (대표님 11/20)
남이 봐 주는 사주보다 내가 보는 내 사주가 제일 정확하다. 내 삶을 가장 잘 아는 사람이 나이기 때문이다. 내 사주를 스스로 읽어서 내 삶을 조금 더 잘 살아가게 돕는다.

> 남이 읽어 주는 사주는 그날 한 번이지만, 내가 읽는 사주는 평생 쓴다.

## 형식: 가이드북
- 만세력 화면 한 장을 펴 놓고, 보이는 순서대로 하나씩 짚는다.
- 장마다 같은 네 칸
  1. **화면에서 찾기**: 만세력 그림에 동그라미
  2. **뜻**: 이 칸이 무엇인지 한 줄, 그다음 풀이
  3. **이렇게 읽는다**: 단계별 순서, 예시 사주로 실제로 읽어 보기
  4. **내 것 적어 보기**: 빈칸과 체크리스트
- 장 끝에 '흔한 오해' 한 상자
- 계산은 사이트(hundosaju.com 무료 풀이 만세력)에 맡긴다. 책은 읽는 법만 가르친다. 그래서 입춘, 야자시, 경도 보정에서 틀릴 일이 없다.

## 고전 근거 (책 앞머리)
- 『논어』 요왈: 不知命 無以爲君子 (명을 모르면 군자가 될 수 없다)
- 『맹자』 진심 상: 知命者 不立乎巖墻之下 (명을 아는 이는 무너질 담 밑에 서지 않는다)
- 『요범사훈』: 命由我作 福自己求 (명은 내가 짓고 복은 스스로 구한다)
- 『적천수』 생시론: 같은 사주도 시각, 사는 곳, 집안에 따라 삶이 다르다 → 사주는 판이고, 삶은 내가 둔다
- 반대 목소리 "자기 사주는 자기가 제일 못 본다"를 정면으로 다룬다: 좋은 건 크게 나쁜 건 작게 읽는 버릇 → '느낌'이 아니라 '실제로 있었던 일'을 묻는 체크리스트로 막는다

## 목차 (안)

### 0부 시작하기 전에
- 0-1 왜 내가 읽는가 (위 고전 근거)
- 0-2 내 만세력 뽑기: 사이트에서 생일 넣기, 태어난 시를 모를 때
- 0-3 이 책 쓰는 법: 장마다 네 칸, 연필 하나

### 1부 만세력 화면 한 장 읽기
- 1장 여덟 칸의 자리: 네 기둥(연 월 일 시), 위 줄 천간과 아래 줄 지지, 오른쪽부터 읽는 이유
- 2장 나는 어디 있나: 태어난 날 위 글자(일간)가 나. 일간 열 가지
- 3장 다섯 색깔: 오행 세기, 많은 기운과 없는 기운
- 4장 글자 옆 작은 이름: 십신 열 개를 다섯 묶음으로(비겁 식상 재성 관성 인성)
- 5장 땅 속에 숨은 글자: 지장간
- 6장 아래 줄의 표시들: 12운성과 신살은 '참고'까지만 (고전도 신살은 낮게 봤다)
- 7장 맨 아래 띠: 대운(10년)과 세운(1년)

### 2부 내 사주 뼈대 잡기, 다섯 단계
- 1단계 일간 확인
- 2단계 태어난 달과 계절(월령)
- 3단계 내 힘 어림하기(신강, 신약) 체크리스트
- 4단계 나에게 필요한 기운(용신) 세 갈래를 쉬운 판으로: 억부, 조후, 격국
- 5단계 내 사주의 모양 이름 붙이기(격)

### 3부 궁금한 것별 찾아보기 (이 책의 중심)
질문마다: 볼 칸 → 읽는 순서 → 예시 → 내 것 적기

| 궁금한 것 | 먼저 볼 칸 | 함께 볼 것 |
|---|---|---|
| 나는 어떤 사람인가 | 일간 | 태어난 달, 가장 많은 기운 |
| 어떤 일이 맞나 | 식상과 관성 | 태어난 달 기둥, 필요한 기운 |
| 돈은 어떻게 모이나 | 재성 | 내 힘(신강, 신약), 식상이 재성을 낳는지 |
| 어떤 사람과 연애하나 | 태어난 날 아래 글자(배우자 자리) | 재성과 관성, 합과 충 |
| 가족과 나 | 연, 월, 시 기둥의 자리 | 인성(부모), 비겁(형제), 식상과 관성(자식) |
| 몸은 어디를 챙기나 | 많은 기운과 없는 기운 | (의학이 아님을 밝힘) |
| 올해와 내년 운 | 그해의 두 글자 | 내 사주 글자와 합, 충 |
| 10년 흐름 | 대운 | 필요한 기운이 오는 때 |
| 그 사람과 잘 맞나 | 두 사람 일간 | 배우자 자리 합과 충 |
| 시험, 이직, 이사 시기 | 세운과 대운 | 관성, 인성, 역마 |

### 4부 해석이 갈리는 자리
입춘과 설날, 절기와 초하루, 야자시, 경도 보정과 서머타임, 용신 세 갈래, 신살 기준(띠 또는 날), 대운 시작 나이. 각 쟁점마다 A설, B설, 훈도사주 엔진의 선택과 이유. (명리 공부 지도 4번 표가 원본)

### 5부 처음부터 끝까지 읽어 보기
가상 인물 세 명의 사주를 1~4부 순서대로 끝까지 읽는다. 실존 인물과 손님 사주는 쓰지 않는다.
