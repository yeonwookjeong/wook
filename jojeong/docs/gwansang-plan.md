## 기획 요약

- 지금 랩은 찍을 때마다 `/api/portrait`를 자동 호출한다(최대 2회). 시험 비용의 원인. 무료 흐름에서 이 호출을 없애고, 결과 그림 자리는 기기 안에서 그린 먹선 얼굴(`InkFace`)로 대신한다.
- 시연 흐름: 첫 화면("사진은 그대 폰 밖으로 나가지 않사옵니다") → 4초 촬영 → 곧바로 무료 결과 → 사진 없는 공유 카드 → (원하면) 초상화 별도 동의·결제 → 생성 → 사주로 연결.
- 소개 원칙: 실제 사람 얼굴 풀이·외모 순위 금지, 등급은 얼굴 전체가 아니라 자리(이마·코…)에만, 경계 뒤엔 대비, "얼굴에 적혀 있다" 금지, 재미로 보는 것임을 밝힘. 첫 줄 후보: "소신이 일하던 관상감, 사실 얼굴 보는 곳이 아니었사옵니다."
- 원가: 초상화 1장 약 190원, 다시 그리면 약 381원(Gemini 3 Pro Image $0.134/장, 2026-10-21 확인, 환율 1,400원 가정).
- 법·규제 확인 필요: 얼굴 사진 국외 이전(개인정보처리방침 3항 개정), 생체인식정보 해당 여부, 만 14세 미만, AI 생성물 표시, Gemini 입력 학습 사용 여부.
- 화면 문구 수정 필요: 랩의 "어디에도 저장되지 않아요"는 Gemini API 오용 감시 보관(55일)과 맞지 않는다.
