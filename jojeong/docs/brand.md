## 2. 글자 대비 (WCAG 기준)

대비는 사이트 한지 #f4ecdb 기준으로 계산했다. 본문과 작은 글씨는 바탕과의 대비가 **4.5 이상**, 24px 넘는 큰 제목은 **3 이상**이어야 한다.

| 조합 | 대비 | 판정 |
|---|---|---|
| 먹 / 한지 | 14.48 | 좋음 |
| 연한 먹 / 한지 | 6.05 | 좋음 |
| 주홍 / 한지 | 5.56 | 좋음 |
| 사이트 금 #86601a / 한지 | 4.83 | 좋음 |
| **카드 금 #d9b465 / 한지** | **1.65** | **금지. 카드 금은 남색 위 글자와 한지 위 선, 장식에만** |
| 카드 금 #d9b465 / 남색 | 8.40 | 좋음 |
| 한지 글자 / 남색 | 13.83 | 좋음 |

흐리게 만든 글자 (투명도)도 같은 기준을 지킨다.

| 클래스 | 바탕 | 대비 | 판정 |
|---|---|---|---|
| `text-ink-soft/80` | 한지 | 3.88 | 작은 글씨 금지 |
| `text-ink-soft/70` | 한지 | 3.16 | 작은 글씨 금지 |
| `text-ink-soft/40` | 한지 | 1.82 | 금지 |
| `text-ink/60` | 한지 | 4.24 | 작은 글씨 금지 |
| `text-hanji/55` 이상 | 쪽빛 | 4.7 이상 | 좋음 |
| `text-hanji/50` | 쪽빛 | 4.13 | 작은 글씨 금지 |

흐린 보조 글자가 필요하면 투명도를 내리지 말고 `text-ink-soft`를 그대로 쓴다.

## 3. 글자 크기

휴대폰에서 한글은 영어보다 획이 많아 작은 크기에서 먼저 뭉개진다.

| 쓰임 | 크기 | 줄 간격 |
|---|---|---|
| 출처, 사업자 정보 같은 맨 작은 글 | 12 | 1.5 |
| 보조 설명, 버튼 아래 안내 | 13 또는 14 | 1.55 |
| 본문 | 15 또는 16 | 1.65 |
| 카드 제목 | 18 | 1.4 |
| 화면 제목 | 24에서 28 | 1.25 |
| 첫 화면 큰 제목 | 32에서 40 | 1.15 |

- 12보다 작은 글자는 쓰지 않는다. 10.5, 11, 11.5, 12.5 같은 중간 크기도 새로 만들지 않는다.
- 한 화면에 쓰는 크기는 다섯 가지를 넘기지 않는다.
- 굵기는 보통 400, 500, 제목 700. 800 이상은 첫 화면 큰 제목과 카드 숫자에만.
- 함렛은 제목과 숫자에, 본문과 버튼은 본고딕 계열에 둔다.

2026-11-13 코드 기준 남은 숙제: `text-[11px]` 291곳, `text-[10.5px]` 79곳, `text-[11.5px]` 61곳, `text-[12.5px]` 66곳. 화면을 고칠 때마다 위 표의 크기로 옮긴다.

## 4. 간격

4의 배수만 쓴다: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96.

| 자리 | 간격 |
|---|---|
| 버튼, 입력칸 안쪽 | 4에서 12 |
| 목록의 줄과 줄 사이 | 4에서 8 |
| 묶음과 묶음 사이 (제목과 그 목록, 카드 둘) | 12에서 24 |
| 단락과 단락 사이 | 32에서 64 |
| 휴대폰 화면 좌우 여백 | 16 또는 20 |

- 같은 목록의 줄은 높이와 간격이 같아야 한다.
- 묶음 안 간격은 묶음 사이 간격보다 작아야 한다. 아니면 어디까지가 한 묶음인지 안 보인다.
- 나란한 카드는 안쪽 여백이 같아야 한다.
- 버튼 높이는 손가락 기준 44 이상.

| 요소 | 둥글기 |
|---|---|
| 작은 표시, 태그 | 4에서 6 |
| 버튼, 입력칸 | 8에서 10 |
| 카드 | 12에서 16 |

## 6. 한 화면 점검표

화면을 새로 만들거나 고칠 때 아래를 하나씩 본다.

1. 강조색(주홍)이 한 화면에 한두 곳뿐인가. 모든 게 강조되면 아무것도 강조되지 않는다.
2. 보라에서 파랑 같은 그라데이션, 빛나는 그림자, 흐릿한 색 덩어리가 없는가.
3. 이모지를 아이콘이나 꾸밈으로 쓰지 않았는가. 아이콘은 한 종류, 한 크기.
4. 느낌표, "!!", "놀라운", "완벽한" 같은 부풀린 말이 없는가. 대신 무엇을 해 주는지 쓴다.
5. 출처 없는 숫자 ("10만 명이 선택") 가 없는가. 실제 숫자만, 조용히.
6. 주된 버튼은 하나, 보조 버튼은 많아야 하나.
7. 글자 대비 4.5, 글자 크기 12 이상, 간격 4의 배수를 지켰는가.
8. 모든 것을 가운데 정렬로 쌓지 않았는가. 긴 글은 왼쪽 정렬.
