# 훈도사주 상품 기획 2027 (확정 초안, 2026-10-10)

## 원칙
- 상한 1만 원 미만.
- 무료는 AI 없음(계산만). 예외는 하나: 카카오 가입자 첫 고민 1개.
- 원가(이전 확인값): 보고서 1편 AI 약 70~240원(Gemini, 열 때만, 재열람 0원), 답장 1개 수십 원.
  990원 단품도 65~80%가 남는다. 가격 조정 이유는 원가가 아니라 가치와 객단가.

## 손님 여정
1. 발견: 스레드·인스타(칸 글, 릴스) / 검색(칼럼·블로그) / 친구 공유 / 선물
2. 첫 화면: 생일 입력 하나. SNS 글 주제에 맞는 화면으로 바로.
3. 무료(AI 없음): 사주표 8칸 → 100명 중 몇 명 특징 → 과거 확인 한 줄 → 판정(이유는 잠금) → 문은 하나 "정 훈도에게 묻기"
4. 카카오로 가입 → 첫 고민 1개 무료(이어 묻기 2번)
5. 고민권 결제 → 대화 중 "한 권으로" → 보고서
6. 다시 오게: 오늘의 운세, 일주 순위, 60일주 도감, 상담방 "오늘 그대의 날"
7. 데려오게: 공유 카드, 궁합 상대 초대, 선물하기

## 상품과 가격 (2026-10-10 회의 확정, A안)
단품은 990 / 1,900 / 2,900 세 단계. 상품 가치(분량·쓰는 기간·마음의 강도)에 따라 나눈다.
| 단계 | 상품 | 가격 |
|---|---|---|
| 무료 | 사주표(만세력보다 자세히, 해석은 최소) + 2027 판정·12달 그래프 | 0원 |
| 입구 | 택일(모든 종류) / 연애 / 재물 / 직업 / 다른 해 운세 / 질문 1개 | 990원 |
| 중간 | 2027 총운 / 궁합 | 1,900원 |
| 대표 | 평생 사주 | 2,900원 |
| 세트 | 새해 세트(평생+2027+재물) | 3,900원 (단품 합 5,790원) |
| 세트 | 다 보기(평생+2027+연애+재물+직업) | 4,900원 (단품 합 7,770원) |
| 질문 묶음 | 5개 / 10개 | 2,900원 / 4,900원 |
| 가입 선물 | 카카오 가입 시 질문 1개 | 무료 |
- 보고서마다 질문 1개 동봉, 세트는 3~5개.
- 버튼·가격표는 쉬운 말("질문", "물어보기"). 조선 이름(소지·소지함·제사)은 상담방 안에서만.
- 선물하기: 위 상품 그대로, 결제 때 받는 분 생일 입력(충전식 이용권 아님).

## 무료 화면 원칙
- 디자인·표·그래프는 지금 것 그대로, 정보(이름표·숫자·한자)는 더 많이, 해석 문장은 뺀다.
- 사주표 아래 만세력 줄(십성·지장간·12운성·신살), 대운은 등급+제목+글자 관계 꼬리표만, 2027 판정 칩+12달 막대.
- 블록마다 "이게 무슨 뜻이옵니까? 훈도에게 묻기 →". 새 블록은 모두 엔진 계산(AI 0원).

## 보고서 품질 (11월 전 우선: 1·2·4)
1. 2027 달력: 달마다 좋은 날 3개(택일 엔진 재사용) + 할 일
2. 맞힘 먼저: 첫머리 과거 확인 2~3줄
3. 평생 사주 한 장 요약 카드
4. 장마다 "훈도에게 묻기"
5. 대운 그래프, 궁합 두 사주표 합·충 그림
6. 서찰 디자인 이미지/PDF 저장
