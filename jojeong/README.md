# 왕이 될 사주 — 관상감 막내 정 훈도가 봐드리는 궁중 사주

생년월일을 넣으면 왕으로 즉위해 **내가 어떤 왕인지(왕 유형 10종 + 실록 속 같은 사주의 왕)**를 먼저 보고, 초대 링크로 들어온 친구들이 사주 궁합에 따라 영의정부터 간신·유배까지 관직을 받는 바이럴 웹.

## 실행

```bash
cd jojeong
npm install
npm run dev        # http://localhost:3000
```

로컬에서는 데이터가 `.data/db.json`에 저장됩니다(별도 DB 불필요).

## 배포 (Vercel)

1. Vercel에서 이 저장소를 Import → **Root Directory를 `jojeong`**으로 지정
2. Storage 탭 → Marketplace에서 **Upstash Redis**(무료 플랜) 추가 → 프로젝트에 연결
   - `KV_REST_API_URL` / `KV_REST_API_TOKEN` 또는 `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`이 자동 주입됩니다. 둘 다 인식합니다.
3. 커스텀 도메인을 붙이면 환경변수 `NEXT_PUBLIC_SITE_URL=https://도메인` 추가 (카톡 미리보기 이미지 주소에 쓰임)

Redis 환경변수 없이 Vercel에 배포하면 즉위 시 오류가 나도록 되어 있습니다(서버리스는 파일 저장이 안 되기 때문).

## 구조

| 경로 | 내용 |
|---|---|
| `/` | 즉위 (왕 생성) |
| `/court/[id]` | 조정. 왕에게는 신하 목록·초대 버튼·직접 등용 폼(생년월일을 아는 신하를 왕이 직접 입력)·파직 버튼, 처음 온 사람에게는 입궐 폼 |
| `/court/[id]/m/[mid]` | 신하 한 명의 교지 + 밀지(사주 풀이). 왕에게는 "○○에게 교지 보내기" 버튼 |
| `/opengraph-image` | 메인 주소 링크 미리보기: 일월오봉도 병풍 그림 + 소개 문구 (1200×630, 빌드 때 한 번 생성) |
| `/court/[id]/opengraph-image` | 카톡 초대 미리보기 (1200×630) |
| `/court/[id]/m/[mid]/opengraph-image` | 결과 링크 미리보기 (1200×630) |
| `/court/[id]/sillok` | 실록 요약 카드(등급·총평·오행·평가·별명) 스토리 이미지 (1080×1920) |
| `/court/[id]/king` | 즉위 교서(왕 유형) 스토리 이미지 (1080×1920) |
| `/court/[id]/gyoji` | 조정도 스토리 이미지 (1080×1920) |
| `/court/[id]/m/[mid]/card` | 개인 교지 스토리 이미지 (1080×1920) |

- `lib/saju.ts`: 만세력 계산(`lunar-javascript`, 입춘 기준) → 일간 오행 생극 + 천간합·육합·반합·충·원진·띠·시지로 점수와 관직 결정
- `lib/roles.ts`: 관직별 카피(정 훈도 말투). 문구 수정은 여기서
- `lib/myeongri.ts`: 여덟 글자 전체 풀이(새로 즉위·입궐한 사람부터). 연주·월주는 태어난 시각 기준(입춘·절기 당일도 정확), 시주 천간은 일간+시지로 계산
  - 오행 분포, 십신(지지는 본기 기준), 신강/신약(월지 가중 3·일지 1.5·나머지 1, 실제 분포 기준 극신강 16%·신강 34%·신약 36%·극신약 13%), 억부 용신·기신
  - 실록 요약에 사주 원국·오행 막대·신강/용신·"없는 오행 = 나라에 없는 것" 표시, 6항목 별점은 십신 가중치로 계산(항목마다 실제 분포 기준 1~5점)
  - 궁합 점수에 왕의 용신 오행을 많이 가진 신하 가점·기신 많은 신하 감점(평균 0으로 맞춰 관직 분포 유지). 밀지에 "전하께 모자란 ○ 기운" 문구
  - 기존 조정(4글자만 저장)은 예전 방식 그대로 동작
- `lib/reign.ts`: 실록의 판정. 전부 사주 근거 문장(정 훈도의 소견)과 함께 나옴
  - 수명: 일지-일간 관계, 일지-띠 충·원진·합, 시지-일지 충·합으로 점수 → 향년 14~90세. 보정 없이 단명 사주는 10대에 승하. 전체 평균 46.1세(실제 조선 왕 평균과 같음)
  - 군주 등급: 띠(백성)와 일간(왕)의 생극 + 일지-띠 관계 → 성군 10% · 명군 36% · 무난 19% · 암군 27% · 폭군 8%
  - 평가 6항목(백성에게·신하에게·외적에게·무예·학문·나라 살림): 일간별 기본 성향 + 등급 보정. 가장 높은 항목과 낮은 항목으로 한 줄 총평
- `lib/sillok.ts` + `lib/episodes.ts`: 가상 실록 본문(같은 사주는 항상 같은 실록). 화면에는 한눈에 보는 요약(등급·총평·평가·별명·소견)이 먼저, 그 아래 장면형 에피소드 7장(세자 시절 → 첫 사건 → 위기 → 별명이 생긴 사건 → 전하의 흠 → 야사 → 마지막 날). 흠은 가장 낮은 평가 항목의 장면 + 신강/신약 한 줄, 야사는 가장 많은 십신의 버릇 + 비어 있는 오행의 버릇. 치세 이름은 가장 높은 평가 항목에서 정함
  - 성군·명군·무난은 밝은 에피소드, 암군·폭군은 같은 성격이 왕좌에서 독이 되는 어두운 에피소드. 폭군은 반정으로 폐위되어 '(이름)군'으로 강등, 유배지에서 사망
  - 조정의 영의정·간신·유배·일반 신하 이름이 등장인물로 들어감(폭군의 반정은 영의정이 이끔). 평균 수명 46.1세·영조 82세는 황상익 교수 연구 인용(문화일보). 문구 수정은 `lib/episodes.ts`
- `lib/pairs.ts`: 신하끼리 궁합(양방향 점수 평균). 조정 화면에 천생연분·앙숙 1쌍씩 무료 노출
- `lib/kingTypes.ts`: 일간별 왕 유형 10종 카피 (성격 해석, 실존 왕 이름은 넣지 않음)
- `lib/kings.ts`: 조선 27왕의 실록 음력 탄일 → 일주 계산. 사용자와 일주가 같으면 그 왕들, 없으면 같은 일간의 왕, 그것도 없으면(경금) "조선 최초의 경금 군주"
  - 탄일은 위키백과·우리역사넷 등에서 수집해 양력 환산일과 대조함. 1582년 이전 날짜는 출처별로 율리우스력/그레고리력 표기가 달라 8~10일 차이가 나는 것이 정상
  - 27왕 일간 분포: 신금 6, 정화 6, 기토 5, 계수 3, 갑목 2, 무토 2, 을목·병화·임수 각 1, 경금 0. 일주 기준으로는 60개 중 22개가 왕과 겹침
- `lib/court.ts`: 조정 서열 정렬, 영의정은 조정 내 최고점 신하에게 동적으로 부여(새 신하가 오면 뺏길 수 있음)
- 생년월일 원문은 저장하지 않고, 계산된 일주·띠·시지만 저장

간신 판정: 상대 일간이 왕을 편관(칠살)으로 극하거나, 정관인데 일지가 충·원진이거나, 겁재인데 일지가 충인 경우 중 천간합·일지 육합·일지 삼합(반합 포함)이 하나도 없고 궁합 70점 미만일 때. 정관은 바른 견제로 보아 대사헌.

실제 출생 사주 무작위 3만 쌍 기준 관직 분포: 좌의정 19%, 예조 16%, 병조 15%, 호조 14%, 대사헌 11%, 대제학 10%, 간신 7%, 유배 6%.

공유 이미지 폰트 `assets/fonts/NanumMyeongjo-*.ttf`는 SIL Open Font License 1.1 폰트(나눔명조, Google Fonts 배포본)입니다.

## 브랜드와 유료 보고서

- 브랜드: **관상감 정 훈도 · 조선 최고의 사주쟁이**. 모든 페이지 위(`SiteHeader`)와 아래(`SiteFooter`)에 訓導 도장 로고. 아래에는 "왕이 될 사주 처음으로", 약관·환불·개인정보 링크, 사업자 정보(`lib/business.ts`를 채우면 표시)
- `/reports`: 정 훈도의 비밀 보고서 목록, `/reports/[id]`: 목차 + 첫 장 맛보기(무료) + 잠긴 나머지 + 가격 + 청약철회 제한 고지. 결제 버튼은 결제 연동 전까지 "결제 준비 중"
  - 2026 국정 운영 보고서 맛보기는 실제 계산: 병오년 천간의 십신·용신/기신으로 길흉, 2026년 열두 달 월주로 좋은 달·조심할 달 개수(어느 달인지는 잠김)
  - 잠긴 부분은 자리표시 막대만 그려서 유료 내용이 페이지 소스에 나가지 않음
  - 조정(왕) 화면과 신하 본인 교지 아래에 보고서 선반(`ReportShelf`)
- `/terms`, `/refund`, `/privacy`: 약관(초안). 사업자 정보는 `lib/business.ts` 한 곳에서 관리하며 푸터·약관에 함께 표시. 개인정보처리방침에 Upstash(도쿄) 국외 이전 명시
- 줄바꿈: 본문은 어절 단위(keep-all) + `text-wrap: pretty`, 가운데 정렬 짧은 문구는 `balance`. `components/Keep.tsx`가 "돈·일·연애" 같은 가운뎃점 묶음과 쉼표 단위 구절을 한 줄로 붙잡음
- `/contact`: 문의하기. 전화 상담 없이 이메일로만 받으며, 문의 종류별로 제목·양식이 채워진 메일을 연다
- 첫 화면에 실제 즉위 수("지금까지 N명의 전하가 즉위") 표시(`stats:courts` 카운터)

## 무료와 유료의 경계

- **사주 엔진** (`lib/myeongri.ts`, `lib/deep.ts`): 자평명리 전 과정
  - 오행·십신 비율은 한국 만세력(포스텔러 등) 방식: 각 글자의 본기 오행, 궁성 보정(천간 2 · 월지 7 · 일지 3 · 연지/시지 2, 총 22), 조후 보정(월지 未→火, 丑→水 전부, 戌→水·辰→木 4/7). 포스텔러 "조후와 궁성 보정값 적용" 결과와 소수점까지 일치 확인
  - 지장간은 격국 판단과 사주표 표시에 사용
  - 합에 따른 오행 변화(합화)는 적용하지 않음(성립 조건이 까다롭고 유파마다 달라, 포스텔러도 기본값은 꺼 둠). 합은 풀이 문장에서만 다룸
  - 신강·신약: 일간 자신을 포함해 돕는 기운(인성·비겁)이 절반 이상이면 신강 (25% 미만 극신약, 70% 이상 극신강), 50%±6%는 중화 근접 표시. 실제 출생 사주에서 신약 약 53%
  - 용신: 억부(강약의 원인에 따라 재극인·관성·식상 / 인성·비겁, 이미 넘치는 오행은 제외) + 조후(한여름 무수·한겨울 무화 우선) · 희신 · 기신
  - 격국(월지 지장간 투출), 12운성, 신살(천을·문창·도화·역마·화개·양인·공망·괴강·백호), 합·충·형·파·해·원진
  - 태어난 시각은 자유 입력("0930", "21:30", "오후 9시 반", "밤 11시" 등을 `parseClock`이 해석해 "오후 9시 30분으로 알아들었사옵니다"로 되짚어 줌) + 출생 도시 검색(`lib/cities.ts`: 국내 50여 곳·해외 130여 곳, 한글·영문·별칭 검색, 각 도시의 경도와 IANA 시간대). 해외 출생은 그 나라의 당시 표준시·서머타임을 tz 데이터로 반영(`lib/birthtime.ts`, `components/BirthTimeFields.tsx`). 한국은 당시 표준시(1954.3.21~1961.8.10 UTC+8:30)와 서머타임(1948~51, 1955~60, 1987~88)을 tz 데이터(Asia/Seoul)로 자동 반영하고, 지역 경도로 지방평균시(서울 −32분, 부산 −24분 등)를 구해 시주를 정함. 입력 칸 아래에 보정 결과를 실시간 표시. 23:00(지방시) 이후는 다음 날 자시(정자시). 연·월주는 보정된 실제 출생 순간으로 절입을 판정. 진태양시(균시차)는 적용하지 않음
- **대운·명반** (`lib/profile.ts`): 입력 시 성별(선택)로 대운, 태어난 시로 명반(iztro)을 계산해 `profile:{court}:{who}`에 저장. 명반은 영역별 풀이를 날카롭게 하는 데만 쓰고 화면에 방법을 드러내지 않음. 기존 사용자는 보고서에서 생년월일 재확인 후 보강(`deepenAction`)
- **2026 신년 운세 (무료 전편)** (`lib/yearly.ts`, `lib/yearText.ts`, `components/YearReport.tsx`): 타고난 그릇(물상·조후·격국·일주 12운성·기질·신살) → 병오년 총운(일간별 해석, 원국 지지와의 합충 전부, 올해 신살) → 10년 대운(교운기 안내) → 재물·일·연애·관계·건강·이동(명반의 丙년 사화가 떨어지는 궁 반영) → 12개월(절기 기준, 용신·일지 합충·귀인) → 개운법(용신 오행의 색·숫자·방위) → 당부. 판정 분포 대길 20 · 길 27 · 평 27 · 조심 20 · 인내 6% 안팎
- **무료**: 조선의 나 + 2026 운세 전편 — 왕 유형·등급·가상 실록, 벗들의 관직과 궁합, **조선 신분 감정**(`lib/sinbun.ts`: 가장 많은 십신 그룹 + 일간 음양으로 12가지 신분·직업. 보고서 선반 맨 앞의 무료 보고서 `/reports/sinbun`으로, 실록처럼 7장: 태어난 집 · 하루 · 사람들이 본 그대(신강약·주도 십신·빠진 오행) · 인생의 고비 · 귀인과 악연(용신·기신) · 출세 · 말년, 끝에 지금 시대의 기질과 직업·적성 보고서 연결)
- **유료 = 지금의 나**: 조선 최고의 사주쟁이 정 훈도가 봐 주는 현재. 모든 보고서 990원, 복채 단골 할인 990 → 890 → 790 → 690원

## 캐릭터: 관상감 막내 · 정 훈도

- 관상감 명과학은 조선 왕실의 궁합 심사·택일·왕실 자녀 사주 기록을 맡은 실제 부서. 명과학 훈도는 경국대전상 정9품 관직
- 조선식 호칭(성 + 관직명)에 따라 "정 훈도". 품계 존칭으로는 "나리", 왕 앞에서는 "소신"
- 설정: 품계는 말단 정9품이지만 사주 보는 눈은 조선 제일. 흰 얼굴의 미남이라 궁녀들 사이에 소문이 자자한 관상감 막내. 관직은 정 훈도가 "천거"하고 왕이 내리는 구조
- 실존 인물(정약용 등)의 후손으로 설정하지 않음. 성씨만 사용
