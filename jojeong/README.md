# 왕이 될 사주 — 관상감 막내 정 훈도가 봐드리는 궁중 사주

생년월일을 넣으면 왕으로 즉위해 **내가 어떤 왕인지(왕 유형 10종 + 실록 속 같은 사주의 왕)**를 먼저 보고, 초대 링크로 들어온 친구들이 사주 궁합에 따라 영의정부터 간신·유배까지 관직을 받는 바이럴 웹.

## 실행

```bash
cd jojeong
npm install
npm run dev        # http://localhost:3000
```

로컬에서는 데이터가 `.data/db.json`에 저장됩니다(별도 DB 불필요).

## 배포 (Vercel)

1. Vercel에서 이 저장소를 Import → **Root Directory를 `jojeong`**으로 지정
2. Storage 탭 → Marketplace에서 **Upstash Redis**(무료 플랜) 추가 → 프로젝트에 연결
   - `KV_REST_API_URL` / `KV_REST_API_TOKEN` 또는 `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`이 자동 주입됩니다. 둘 다 인식합니다.
3. 커스텀 도메인을 붙이면 환경변수 `NEXT_PUBLIC_SITE_URL=https://도메인` 추가 (카톡 미리보기 이미지 주소에 쓰임)

Redis 환경변수 없이 Vercel에 배포하면 즉위 시 오류가 나도록 되어 있습니다(서버리스는 파일 저장이 안 되기 때문).

## 구조

| 경로 | 내용 |
|---|---|
| `/` | 즉위 (왕 생성) |
| `/court/[id]` | 조정. 왕에게는 신하 목록·초대 버튼·직접 등용 폼(생년월일을 아는 신하를 왕이 직접 입력)·파직 버튼, 처음 온 사람에게는 입궐 폼 |
| `/court/[id]/m/[mid]` | 신하 한 명의 교지 + 밀지(사주 풀이). 왕에게는 "○○에게 교지 보내기" 버튼 |
| `/opengraph-image` | 메인 주소 링크 미리보기: 옥좌 그림 + 소개 문구 (1200×630, 빌드 때 한 번 생성) |
| `/court/[id]/opengraph-image` | 카톡 초대 미리보기 (1200×630) |
| `/court/[id]/m/[mid]/opengraph-image` | 결과 링크 미리보기 (1200×630) |
| `/court/[id]/sillok` | 실록 요약 카드(등급·총평·수명 순위·평가·별명) 스토리 이미지 (1080×1920) |
| `/court/[id]/king` | 즉위 교서(왕 유형) 스토리 이미지 (1080×1920) |
| `/court/[id]/gyoji` | 조정도 스토리 이미지 (1080×1920) |
| `/court/[id]/m/[mid]/card` | 개인 교지 스토리 이미지 (1080×1920) |

- `lib/saju.ts`: 만세력 계산(`lunar-javascript`, 입춘 기준) → 일간 오행 생극 + 천간합·육합·반합·충·원진·띠·시지로 점수와 관직 결정
- `lib/roles.ts`: 관직별 카피(정 훈도 말투). 문구 수정은 여기서
- `lib/myeongri.ts`: 여덟 글자 전체 풀이(새로 즉위·입궐한 사람부터). 연주·월주는 태어난 시각 기준(입춘·절기 당일도 정확), 시주 천간은 일간+시지로 계산
  - 오행 분포, 십신(지지는 본기 기준), 신강/신약(월지 가중 3·일지 1.5·나머지 1, 실제 분포 기준 극신강 16%·신강 34%·신약 36%·극신약 13%), 억부 용신·기신
  - 실록 요약에 사주 원국·오행 막대·신강/용신·"없는 오행 = 나라에 없는 것" 표시, 6항목 별점은 십신 가중치로 계산(항목마다 실제 분포 기준 1~5점)
  - 궁합 점수에 왕의 용신 오행을 많이 가진 신하 가점·기신 많은 신하 감점(평균 0으로 맞춰 관직 분포 유지). 밀지에 "전하께 모자란 ○ 기운" 문구
  - 기존 조정(4글자만 저장)은 예전 방식 그대로 동작
- `lib/reign.ts`: 실록의 판정. 전부 사주 근거 문장(정 훈도의 소견)과 함께 나옴
  - 수명: 일지-일간 관계, 일지-띠 충·원진·합, 시지-일지 충·합으로 점수 → 향년 14~90세. 보정 없이 단명 사주는 10대에 승하. 전체 평균 46.1세(실제 조선 왕 평균과 같음)
  - 군주 등급: 띠(백성)와 일간(왕)의 생극 + 일지-띠 관계 → 성군 10% · 명군 36% · 무난 19% · 암군 27% · 폭군 8%
  - 평가 6항목(백성에게·신하에게·외적에게·무예·학문·나라 살림): 일간별 기본 성향 + 등급 보정. 가장 높은 항목과 낮은 항목으로 한 줄 총평
- `lib/sillok.ts` + `lib/episodes.ts`: 가상 실록 본문(같은 사주는 항상 같은 실록). 화면에는 한눈에 보는 요약(등급·총평·평가·별명·소견)이 먼저, 그 아래 장면형 에피소드 6장(세자 시절 → 첫 사건 → 위기 → 별명이 생긴 사건 → 야사 → 마지막 날)
  - 성군·명군·무난은 밝은 에피소드, 암군·폭군은 같은 성격이 왕좌에서 독이 되는 어두운 에피소드. 폭군은 반정으로 폐위되어 '(이름)군'으로 강등, 유배지에서 사망
  - 조정의 영의정·간신·유배·일반 신하 이름이 등장인물로 들어감(폭군의 반정은 영의정이 이끔). 수명 순위는 조선 27왕 실제 향년과 비교. 평균 수명 46.1세·영조 82세는 황상익 교수 연구 인용(문화일보). 문구 수정은 `lib/episodes.ts`
- `lib/pairs.ts`: 신하끼리 궁합(양방향 점수 평균). 조정 화면에 천생연분·앙숙 1쌍씩 무료 노출
- `lib/kingTypes.ts`: 일간별 왕 유형 10종 카피 (성격 해석, 실존 왕 이름은 넣지 않음)
- `lib/kings.ts`: 조선 27왕의 실록 음력 탄일 → 일주 계산. 사용자와 일주가 같으면 그 왕들, 없으면 같은 일간의 왕, 그것도 없으면(경금) "조선 최초의 경금 군주"
  - 탄일은 위키백과·우리역사넷 등에서 수집해 양력 환산일과 대조함. 1582년 이전 날짜는 출처별로 율리우스력/그레고리력 표기가 달라 8~10일 차이가 나는 것이 정상
  - 27왕 일간 분포: 신금 6, 정화 6, 기토 5, 계수 3, 갑목 2, 무토 2, 을목·병화·임수 각 1, 경금 0. 일주 기준으로는 60개 중 22개가 왕과 겹침
- `lib/court.ts`: 조정 서열 정렬, 영의정은 조정 내 최고점 신하에게 동적으로 부여(새 신하가 오면 뺏길 수 있음)
- 생년월일 원문은 저장하지 않고, 계산된 일주·띠·시지만 저장

랜덤 2만 쌍 기준 관직 분포: 예조·병조 각 17%, 간신 14%, 호조·좌의정 각 14%, 대제학 13%, 유배 6%, 대사헌 5%.

공유 이미지 폰트 `assets/fonts/NanumMyeongjo-*.ttf`는 SIL Open Font License 1.1 폰트(나눔명조, Google Fonts 배포본)입니다.

## 유료 상품 (결제 연동 예정)

가상 실록(군주 등급·평가·6장 이야기·수명 순위·사관의 평)은 전부 무료. 유료 상품은 "조선의 전하"를 **지금 현실**로 이어 준다.

| 상품 | 구매자 | 내용 |
|---|---|---|
| 환생 보고서 | 왕 | 전하가 2026년에 환생했다면: 어울리는 직업과 일하는 방식, 연애 스타일, 돈 버는 법 |
| 2026 국정 운영 보고서 | 왕 | 올해(병오년) 운세를 국정처럼: 월별 흐름, 조심할 달, 재물·연애·건강 |
| 신하 뒷조사 | 왕 | 이 친구와 현실에서 어떻게 지내면 좋을지: 같이 일·여행·돈거래 궁합, 다루는 법 |
| 조정 관계도 | 왕·신하 | 모임·팀 전체 케미, 현실 활용(팀플 조 짜기, 여행 방 배정) |
| 조선 신분 감정서 | 누구나 | 내가 조선에 태어났다면: 신분(양반·중인·상민·천민)과 직업(역관·의원·보부상·광대·기생·노비 등), 하루 일과, 그 신분에서의 팔자와 출세 가능성 |
| 내 인사기록 열람 | 신하 | 왕이 받은 나에 대한 보고 + 이 왕(친구)을 현실에서 다루는 법 |

가격: 전 상품 990원. **복채 단골 할인**으로 결제할 때마다 100원씩 내려가 990 → 890 → 790 → **690원(최저, 4회차부터 고정)**. 결제 횟수는 브라우저 쿠키로 추적(쿠키를 지우면 990원으로 돌아갈 뿐이라 악용 여지 없음). 결제 버튼에 실제 결제 금액과 할인액을 미리 표시.

## 캐릭터: 관상감 막내 · 정 훈도

- 관상감 명과학은 조선 왕실의 궁합 심사·택일·왕실 자녀 사주 기록을 맡은 실제 부서. 명과학 훈도는 경국대전상 정9품 관직
- 조선식 호칭(성 + 관직명)에 따라 "정 훈도". 품계 존칭으로는 "나리", 왕 앞에서는 "소신"
- 설정: 품계는 말단 정9품이지만 사주 보는 눈은 조선 제일. 흰 얼굴의 미남이라 궁녀들 사이에 소문이 자자한 관상감 막내. 관직은 정 훈도가 "천거"하고 왕이 내리는 구조
- 실존 인물(정약용 등)의 후손으로 설정하지 않음. 성씨만 사용
