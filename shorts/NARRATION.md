# 내레이션(TTS) 대본 공식: 참고 채널 5편 분석

## 1. 말투·속도 (화면 자막과 오디오로 측정)
- **속도가 매우 빨라요.** 자막 글자 수와 시간으로 재면 초당 약 9음절이에요(평소 말하기는 6~7음절 정도). TTS 기본 속도의 약 1.4~1.5배예요.
- **목소리 높낮이 변화가 커요.** 중간 높이 여성 목소리(약 230~250Hz)이고, 오르내림 폭이 170~370Hz로 넓어요. 단조롭게 읽지 않고 말끝을 올렸다 내렸다 해요.
- **한 문장을 3~4덩어리로 끊어요.** 자막 한 줄이 곧 숨 한 번이에요.

## 2. 문장 패턴 (화면 자막 그대로)
| 역할 | 실제 문장 | 공식 |
|---|---|---|
| 인물 소개 | "시력이 안 좋은 아일릿 민주는" | [특징] + [그룹/직업] + [이름]은 |
| 유명한 사실 | "닝닝은 평소에 절여질(?)만큼 / 향수를 뿌리는 걸로 유명한데" | [이름]은 ~로 유명한데 (괄호 드립) |
| 기간·숫자 | "6~7년째 꾸준히 하고 있다는 / 이시안의 여름철 / 홈케어 루틴?" | [기간] + ~하고 있다는 + [이름]의 + [주제]? |
| 상황 설정 | "공연을 마친 나연이 / 풋기를 뺄 때 / 찐으로 좋은 / 마사지템을 소개하는데" | [상황] + [이름]이 + ~할 때 + [평가] + [제품 종류]를 소개하는데 |
| 대조 | "스케줄 때는 렌즈를 끼지만 / 평상시에는" | A 때는 ~지만 / B 때는 |
| 궁금증 넘기기 | "렌즈 대신 찾은 / 뜻밖의 해결책은" · "이때 이시안의 꿀팁은" | ~은? (답은 셀럽이 말함) |
| 반전 | "그런데 이미 알고 있던 전소미" · "팬들이 못 참고 / 계속 물어보자 결국" | 그런데 / 결국 |
| 과정 설명 | "모델링팩을 / 얼굴 구석구석 발라주고 / 20분 정도 굳혀준 뒤에" | ~하고 / ~한 뒤에 |

## 3. 규칙
1. **3인칭 이야기꾼 말투**로 써요. 반말 리액션("미쳤대", "뭐야?")은 쓰지 않아요.
2. **제품 이름은 내레이션에서 말하지 않아요.** 정답은 셀럽이 공개해요.
3. 문장은 **~는데 / ~지만 / ~은? / ~했다고**로 끝내서 다음 컷으로 넘겨요.
4. 숫자, 기간, 장소("6~7년째", "태국 공항", "3천 원")로 믿음을 줘요.
5. **영상에서 확인된 사실만** 써요. 셀럽이 하지 않은 말("매일 쓴다", "다들 감탄")을 지어내지 않아요.
6. 인터넷 말투를 한 스푼만 넣어요: "찐으로", "절여질(?)만큼".

## 4. 빈칸 템플릿
- 도입: "[특징]인 [이름]이 / [상황]에서 / [사실] [제품 종류]?"
- 연결: "[이름]이 찾은 / 뜻밖의 [해결책·용도]는" 또는 "이때 [이름]의 꿀팁은"
- 반전(선택): "그런데 [다른 사실]"
