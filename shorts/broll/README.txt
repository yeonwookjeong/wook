도입부(첫 TTS) 화면에 쓸 사진·영상 넣는 곳.

자동: 아무것도 안 해도 됨. 폴더가 비어 있으면 '직업 + 이름'(예: 배우 박지현)으로 사진을 찾아
  broll/<이름>/auto_*.jpg로 받아둠. 찾는 곳: 카카오 → 네이버 (키 있을 때만) → 빙(기본, 가입 X) → 위키미디어.
  - 카카오: shorts/kakao_key.txt 에 REST API 키 한 줄 (가장 잘 찾음, 추천)
  - 네이버: shorts/naver_key.txt 에 Client ID(첫 줄), Client Secret(둘째 줄)
  - 키가 없으면 빙 이미지 검색(가입 필요 없음)을 씀. 빙이 막히면 위키미디어(사진 적음)
  얼굴이 한 명만 또렷한 사진만 남김. 마음에 안 드는 사진은 지우면 되고, 다 지우면 다음에 다시 찾음.
  못 찾으면 같은 원본 영상의 예쁜 장면으로 대신함. 끄려면 레시피에 "auto_photos": false

직접: 출연자 이름으로 폴더를 만들고 사진을 넣으면 그게 우선
  broll/박지현/1.jpg, 2.jpg, 3.jpg ...
  broll/이현이/1.jpg, 2.mp4 ...
- 제목의 [[이름]]과 폴더 이름이 같아야 해요.
- 영상마다 3장씩, 같은 출연자 영상끼리 다른 사진이 나오게 돌려 써요 (5~9장 넣으면 겹치지 않음).
- 세로 사진은 위쪽(얼굴) 기준으로 잘려요. 사진은 천천히 확대되는 효과가 들어가요.
- 폴더가 없으면 예전처럼 같은 원본 영상의 예쁜 장면을 씀.

직접 지정: 레시피 tts 구간에 "media": ["broll/박지현/1.jpg", "broll/박지현/2.mp4"]
