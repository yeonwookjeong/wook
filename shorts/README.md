# 셀럽 영상 제품 구간 스캐너

쿠팡 파트너스 쇼츠 소재 찾기용 스캐너입니다. 유튜브 링크를 넣으면 영상을 처음부터 보지 않아도 **제품 얘기가 나오는 시간**을 뽑아줍니다.

| 뽑아주는 것 | 출처 |
|---|---|
| 🔎 키워드 구간 (`써요`, `매일`, `냄새`, `립밤` …) | 한국어 자막, 없으면 자동 자막 |
| 📈 가장 많이 다시 본 구간 Top 3 | 유튜브 진행바 위 그래프 |
| 💬 쓸만한 댓글 | "3:42 이거 어디꺼예요?"처럼 타임스탬프·제품 질문이 있는 인기 댓글 |
| 📝 더보기란 제품 정보 | 설명란의 타임스탬프·제품 줄 |

시간은 클릭하면 바로 그 구간부터 재생되는 링크로 나옵니다.

## 처음 한 번만: 설치
1. 파이썬 3.10 이상을 설치합니다 (https://www.python.org/downloads/). 윈도우는 설치 첫 화면에서 **"Add python.exe to PATH" 체크**를 꼭 하세요.
2. 터미널(윈도우: PowerShell, 맥: 터미널)에서 아래를 실행합니다.
   ```bash
   pip install -U "yt-dlp[default]"
   ```

## 가장 쉬운 실행: 더블클릭
- 윈도우: `run_windows.bat` 더블클릭
- 맥: `run_mac.command` 더블클릭 (막히면 우클릭 → 열기)

유튜브 링크를 붙여넣고 Enter를 누르면 결과 폴더(`out`)가 자동으로 열립니다. 처음 실행할 때는 필요한 도구를 알아서 설치합니다.

## 사용법 (터미널)
`shorts` 폴더에서 실행합니다.
```bash
# 영상 1개 또는 여러 개
python scan.py "https://www.youtube.com/watch?v=XXXX" "https://youtu.be/YYYY"

# 링크를 urls.txt에 한 줄씩 적어두고 한 번에
python scan.py -f urls.txt

# 댓글 수집 빼고 빠르게
python scan.py -f urls.txt --no-comments
```
맥에서 `python`이 안 되면 `python3`로 실행하세요.

## 결과 보는 법
- `out/리포트_날짜시간.md`: 영상별 상세 리포트입니다. 메모장, VS Code, 노션에 붙여넣기 등으로 열면 됩니다.
- `out/구간목록.csv`: 실행할 때마다 아래에 이어서 쌓입니다. 구글시트나 엑셀에 그대로 붙여넣으면 소재 관리 시트가 됩니다.

## 키워드 바꾸기
`keywords.txt`를 메모장으로 열어 수정하세요. 이번 주 카테고리(예: 냄새)만 남기고 나머지 줄 앞에 `#`을 붙이면 결과가 깔끔해집니다.

## 잘 안 될 때
| 증상 | 해결 |
|---|---|
| `실패: ... Sign in / HTTP Error 4xx` | `pip install -U yt-dlp`로 업데이트합니다. 유튜브가 자주 바뀌어서 업데이트가 제일 흔한 해결책이에요 |
| JS 런타임 관련 경고 | 최신 yt-dlp는 유튜브 처리에 [deno](https://deno.com) 설치를 권장합니다. 경고만 나오고 결과가 나오면 무시해도 돼요 |
| "한국어 자막이 없어요" | 자막 없는 영상입니다. 그래프 최고점과 댓글 위주로 보세요 |
| 키워드 구간이 너무 많음 | `keywords.txt`에서 `매일`, `요즘`처럼 흔한 단어를 끕니다 |

# 쇼츠 자동 편집 (make_short.py)

레시피(JSON) 한 장으로 **원본 클립 → TTS 질문 → 원본 클립** 쇼츠를 만듭니다. 상단 제목 2줄, 하단 링크 안내와 출처, 짧게 끊은 자막(셀럽 대사는 흰 글씨, TTS는 노란 박스)과 줌 연출이 들어가고, TTS가 나올 때는 원본 소리가 작아집니다.

```bash
# 처음 한 번 설치
python3 -m pip install -U "yt-dlp[default]" edge-tts pillow imageio-ffmpeg

# 구간 시간만 미리 확인 (빠름)
python3 make_short.py recipes/백진희_발뒤꿈치밤.json --check

# 영상 만들기 → out/쇼츠_백진희_발뒤꿈치밤.mp4
python3 make_short.py recipes/백진희_발뒤꿈치밤.json
```

## 레시피 쓰는 법
- `title1`(빨강), `title2`(검정): 상단 제목 2줄
- `link_text`: 하단 안내 문구 (프로필 링크 번호)
- `parts`: 순서대로 이어 붙일 구간
  - `{"type": "clip", "from": "자막 문구 또는 04:16", "to": "자막 문구 또는 04:25"}`
  - `{"type": "tts", "text": "읽을 문장", "over": "이 장면 위에서 읽기(문구/시간, 생략하면 바로 앞 구간에 이어서)"}`
- 문구는 스캐너 리포트의 자막에서 **몇 글자만 그대로 복사**하면 됩니다. 띄어쓰기와 문장부호는 무시하고 찾아요.
- 폰트를 바꾸려면 `fonts` 폴더를 만들고 .ttf/.otf 파일을 넣으세요 (예: Pretendard Black).

## v2 변경점
- **원본 영상에 박힌 자막 가리기**: 원본 아래쪽 20%를 잘라내고 씁니다. 레시피의 `"src_crop_bottom": 0.2` 값으로 조절하세요. 원본 자막이 더 위에 있으면 0.25~0.3으로 올리면 됩니다.
- **컷 정밀도**: 자동자막의 단어별 시간으로 자르고, 말 사이 쉼에 맞춰 컷 위치를 보정해서 문구 뒤에 다른 말이 따라붙지 않게 했습니다.
- **자막**: 13자 안팎의 짧은 한 줄로 끊어서 말하는 타이밍에 맞춰 넘어갑니다. 셀럽 대사는 흰 글씨에 검정 테두리, TTS는 노란 박스예요.
- **연출**: 원본 구간은 천천히 줌인과 줌아웃을 번갈아 하고, TTS 구간은 확 당겨서 강조합니다.
- **소리**: TTS가 나오는 동안 원본 소리를 7%로 줄입니다.
- **TTS**: `gemini_key.txt`에 Google AI Studio 키를 넣으면 Gemini TTS를 씁니다. `python3 make_short.py --voice-test`로 여성 목소리 5종을 비교한 뒤 레시피 `"gemini_voice"`에 고른 이름을 적으세요.

## v3.1 연출
- 구간 사이에 **전환 효과**가 0.22초씩 들어가요. 줌인, 슬라이드, 흰 화면 번쩍, 위로 밀기, 원형 열림이 번갈아 나오고, 전환할 때마다 '슉' 효과음도 함께 나와요.
- 각 구간이 시작할 때 **툭 당겼다 풀리는 펀치 줌**이 들어가요. 원본 구간은 8% 줌인과 줌아웃이 번갈아 나오고, TTS 구간은 더 크게 당겨요.
- 레시피에서 끄는 법: `"transitions": false`, `"sfx": false`, `"punch_zoom": false`

## 자막 디자인 고르기
레시피에 `"sub_theme": "이름"`을 넣으세요. 기본값은 `premium`이에요.

| 이름 | 셀럽 대사 | TTS |
|---|---|---|
| `premium` | Pretendard Black 흰 글씨, 얇은 테두리와 그림자, 핵심 단어(키워드·숫자)는 초록. 살짝 커지며 '팝' 하고 등장 | 노란 글씨 |
| `clean` | 반투명 검정 바 + 흰 글씨 | 초록 바 + 검정 글씨 |
| `variety` | 노란 굵은 글씨 + 두꺼운 테두리 + 그림자 (예능 자막) | 빨간 박스 + 흰 글씨 |
| `bubble` | 흰 말풍선 + 검정 글씨 | 검정 말풍선 + 흰 글씨 |
| `minimal` | 흰 글씨 + 얇은 테두리 + 그림자 | 초록 글씨 |
| `pop` | 흰 글씨 + 굵은 검정 테두리 (v2) | 노란 박스 |

폰트: `assets/fonts`에 [Pretendard](https://github.com/orioncactus/pretendard)(SIL OFL 1.1, 상업적 사용 가능)가 함께 들어 있어요. 다른 폰트를 쓰려면 `fonts` 폴더에 넣으면 그 폰트가 먼저 쓰여요.

## 자막 없이 (원본 자막 살리기)
레시피에 `"clip_subs": false`를 넣으면 원본 구간에는 내 자막을 넣지 않고, 원본에 박혀 있는 자막을 그대로 보여줘요(기존 계정 방식). TTS 구간만 원본 아래쪽을 잘라내고 TTS 자막을 넣어요. 다시 내 자막으로 돌리려면 `true`로 바꾸세요.

```bash
for f in recipes/*.json; do python3 make_short.py "$f"; done
```

## TTS 음성 직접 넣기 (캡컷·타입캐스트 등)
`my_tts` 폴더에 음성 파일을 넣고 tts 구간에 `"audio"`를 적으세요. 자막은 `"text"`로 나와요.
```json
{"type": "tts", "text": "3천 원짜리로 발뒤꿈치 관리를 한다고?", "audio": "my_tts/발뒤꿈치_질문.mp3"}
```
- Gemini 말투는 레시피의 `"tts_style"`(영어 지시문)로 바꿀 수 있어요.
- 실행하면 `🔊 TTS: Gemini Zephyr`처럼 실제로 쓰인 엔진이 표시돼요. `edge-tts(구형 무료)`로 나오면 Gemini 키가 안 읽힌 거예요.

## ElevenLabs TTS (추천: 가장 자연스러운 한국어)
1. elevenlabs.io 가입 → 상업적으로 쓰려면 유료(Starter 이상) 요금제
2. 프로필 → API Keys에서 키를 만들고, `shorts/elevenlabs_key.txt`에 붙여넣기
3. Voices → Voice Library에서 `Korean`으로 검색 → 마음에 드는 여성 목소리를 **Add to my voices**
4. `python3 make_short.py --list-voices`로 ID를 확인하고 레시피에 `"eleven_voice": "ID"` (없으면 한국어 목소리를 자동 선택)

키가 있으면 ElevenLabs가 Gemini보다 먼저 쓰여요. tts 구간의 `"say"`에는 `[surprised]`, `[curious]`, `[excited]` 같은 감정 태그를 넣을 수 있고(eleven_v3), 자막에는 `"text"`가 나와요.

## Google Cloud TTS (월 무료 한도 안에서 무료)
`shorts/google_tts_key.txt`에 구글 클라우드 API 키를 넣으면 ElevenLabs 다음 순위로 쓰여요. 기본 목소리는 `ko-KR-Chirp3-HD-Aoede`이고, `python3 make_short.py --voice-test`로 여성 목소리 6종을 비교한 뒤 레시피 `"google_voice"`에 적으세요. 말하는 속도는 `"google_rate"`(기본 1.1)로 조절해요.

## TTS 멘트 공식 (예고 → 회수)
TTS는 질문으로 묻는 게 아니라 **다음 장면을 궁금하게 만드는 연결 멘트**로 써요. 셀럽이 바로 다음 장면에서 답하게 배치하고, 2초 안팎의 반말로 짧게 써요.
- 사용처 예고: "근데 이걸 어디에 바르냐면" → 셀럽: "발뒤꿈치에 바르면…"
- 효과 예고: "근데 바른 느낌이 진짜 미쳤대" → 셀럽: "손에 벨벳 씌운 느낌"
- 상황 예고: "흰 옷에 김치국물 튀어도 이걸로 바로 지운대" → 셀럽: "아주 잘 지워져서"
- 셀럽이 바로 다음에 하는 말을 TTS로 미리 말하지 않기 (중복)
- 효과를 과장하는 표현(완치, 100% 등)은 쓰지 않기

## 배경음악 (선택)
기본은 배경음악 없음(원본 소리 그대로)이에요. 쓰려면 `bgm` 폴더에 상업적 사용이 허용된 mp3를 넣고 레시피에 `"bgm": "bgm/파일.mp3"`를 적으세요. 말소리가 나오면 자동으로 작아지고 끝에서 페이드아웃돼요. 크기는 `"bgm_volume"`(기본 0.12)으로 조절해요.

## 업로드용 문구
영상을 만들면 같은 이름의 `.txt`에 제목, 캡션, 해시태그, 쿠팡 파트너스 고지 문구가 함께 저장돼요. 해시태그는 레시피 `"hashtags": ["...", "..."]`로 바꿀 수 있어요.

## story 스타일 (참고 채널 2 실측)
레시피에 `"theme": "story", "sub_theme": "story", "clip_subs": true`를 넣으면 이렇게 나와요.
- 흰 상단 위에 작은 출처, 검정 박스 제목(`[[ ]]`는 노랑), 흰 알약 부제가 들어가고, 그 아래는 전부 영상이에요.
- 셀럽 대사는 “따옴표” 자막에 핵심 단어가 노랑이고, TTS는 3인칭 내레이션 흰 자막을 짧게 끊어서 보여줘요.
- 구성은 **내레이션 도입 → 셀럽 대사 → 내레이션 연결 → 셀럽 대사**예요.

## TTS 도입부 자료(B-roll) + 로고 블러
- tts 구간에 `"media"`를 적으면 TTS가 나오는 동안 그 자료들을 순서대로 보여줘요(사진은 천천히 줌). 파일이 없으면 건너뛰어요.
  - 내 파일: `"broll/백진희_1.jpg"` (인스타 캡처, 다른 영상 등은 `broll` 폴더에 넣기)
  - 같은 영상의 다른 장면: `{"at": "01:52"}`
  - 다른 유튜브 영상의 장면: `{"src": "유튜브링크", "at": "00:10"}`
- `"blur": true`(기본)이면 원본 좌상단·우상단(채널 로고 자리)을 흐리게 해요. 끄려면 `false`, 영역을 직접 지정하려면 `[[x, y, 너비, 높이], ...]`(화면 비율 0~1)로 적어요.
- `"sub_theme": "story_green"`: 셀럽 대사는 “따옴표”, 핵심 단어는 채널 초록색이에요.
- 다른 영상 장면을 시간 없이 `{"src": "링크", "at": "auto", "n": 0}`로 적으면, '많이 다시 본 구간'(없으면 영상 전체에 고르게)에서 볼만한 장면을 자동으로 골라요. `n`을 0, 1, 2…로 바꾸면 다른 장면이 나와요.

## 도입부 자료 자동 등록
- 첫 TTS(도입부)의 `"media"`에 `"auto"`를 넣거나 `media`를 아예 비워두면, **제목의 `[[이름]]` + "브이로그"로 유튜브를 검색**해요. 원본을 뺀 상위 영상 3개에서 '많이 다시 본 장면'을 하나씩 가져와요.
- 검색어는 `"broll_query": "백진희 브이로그"`로 바꿀 수 있어요. 같은 셀럽으로 여러 편을 만들 땐 `"broll_offset": 0, 1, 2…`로 편마다 다른 장면을 쓰게 하세요.
- 자동 등록을 끄려면 `"auto_broll": false`로 두세요.

## 크리에이티브 커먼즈(CC) 영상만 쓰기
- 스캐너가 영상마다 **라이선스**를 보여줘요(✅ CC / ⛔ CC 아님). `--full`을 붙이면 전체 자막을 `out/자막_영상ID.txt`로 저장해요.
- 편집기는 원본이 CC가 아니면 경고를 띄우고, 자동 B-roll은 **CC 필터로만 검색**하고, 받은 영상이 CC가 아니면 건너뛰어요.
- CC BY는 **원작자와 원본 링크 표기**가 조건이에요. 업로드 문구(.txt)에 원본 영상 채널·제목·링크가 자동으로 들어가요.

## 도입부 자료: 소리 없이, 예쁜 장면 위주로
- 도입부 자료는 **CC가 아니어도 써요**(원본 내용 영상만 CC). 도입부 자료 영상의 소리는 쓰지 않아요. CC만 쓰고 싶으면 `"broll_cc_only": true`로 두세요.
- 기본 검색어는 **"[이름] 화보 메이킹"**이에요. 후보 장면 20여 개를 찍어서 **선명함, 색감, 밝기, 얼굴 크기**로 점수를 매긴 뒤 높은 순으로 써요.
- 얼굴 점수까지 쓰려면 한 번만 설치하세요(선택): `python3 -m pip install "opencv-python-headless<5"`

## 컷 편집 v4 (빡빡하고 매끄럽게)
- **쉼 잘라내기:** 원본 구간에서 말 사이 0.35초 넘는 쉼을 잘라내요. 잘라낸 곳은 화면 크기를 1.0↔1.1로 번갈아 바꾸는 '줌 점프컷'이라 튀어 보이지 않아요. 끄려면 `"tighten": false`
- **말 속도:** 말이 느린 사람은 초당 7.2음절 기준으로 최대 1.18배까지 살짝 빠르게 해요(목소리 높이는 그대로). 고정하려면 `"clip_speed": 1.1`, 끄려면 `1.0`
- **전환:** 화려한 전환과 펀치 줌을 빼고, 장면 사이에는 4프레임 디졸브만 써요. '슉' 효과음은 기본으로 꺼져 있어요(`"sfx": true`로 켜기).
- **도입부 자료:** 기본은 **같은 원본 영상에서 본문에 안 쓴 예쁜 장면**이에요(다른 사람이 나올 일 없음). 유튜브 검색을 쓰려면 `"broll_search": true`

## 업로드 일정표 (plan.py)

레시피를 여러 명 쌓아두고 한 번에 영상 만들기 + 예약 업로드 순서 정하기.

```bash
python3 plan.py --make                # 없는 영상만 차례로 만들고(20초 간격) 일정표 저장
python3 plan.py --start 2026-11-03    # 일정표만 다시 (시작 날짜 지정)
python3 plan.py --per-day 2           # 하루 2개 (12:30, 19:30)
```

- 한 원본 영상에서 최대 3개 (넘으면 앞 3개만)
- 같은 원본 영상은 최소 2일 간격 (`--gap`), 같은 출연자는 하루 1개
- 결과: `out/업로드_일정.csv` (날짜·시각·영상·캡션 파일·준비 여부) → 틱톡/유튜브/인스타 예약 업로드에 그대로 걸기
