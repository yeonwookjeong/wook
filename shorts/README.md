# 셀럽 영상 제품 구간 스캐너

쿠팡 파트너스 쇼츠 소재 찾기용 스캐너입니다. 유튜브 링크를 넣으면 영상을 처음부터 보지 않아도 **제품 얘기가 나오는 시간**을 뽑아줍니다.

| 뽑아주는 것 | 출처 |
|---|---|
| 🔎 키워드 구간 (`써요`, `매일`, `냄새`, `립밤` …) | 한국어 자막, 없으면 자동 자막 |
| 📈 가장 많이 다시 본 구간 Top 3 | 유튜브 진행바 위 그래프 |
| 💬 쓸만한 댓글 | "3:42 이거 어디꺼예요?"처럼 타임스탬프·제품 질문이 있는 인기 댓글 |
| 📝 더보기란 제품 정보 | 설명란의 타임스탬프·제품 줄 |

시간은 클릭하면 바로 그 구간부터 재생되는 링크로 나옵니다.

## 처음 한 번만: 설치
1. 파이썬 3.10 이상을 설치합니다 (https://www.python.org/downloads/). 윈도우는 설치 첫 화면에서 **"Add python.exe to PATH" 체크**를 꼭 하세요.
2. 터미널(윈도우: PowerShell, 맥: 터미널)에서 아래를 실행합니다.
   ```bash
   pip install -U "yt-dlp[default]"
   ```

## 가장 쉬운 실행: 더블클릭
- 윈도우: `run_windows.bat` 더블클릭
- 맥: `run_mac.command` 더블클릭 (막히면 우클릭 → 열기)

유튜브 링크를 붙여넣고 Enter를 누르면 결과 폴더(`out`)가 자동으로 열립니다. 처음 실행할 때는 필요한 도구를 알아서 설치합니다.

## 사용법 (터미널)
`shorts` 폴더에서 실행합니다.
```bash
# 영상 1개 또는 여러 개
python scan.py "https://www.youtube.com/watch?v=XXXX" "https://youtu.be/YYYY"

# 링크를 urls.txt에 한 줄씩 적어두고 한 번에
python scan.py -f urls.txt

# 댓글 수집 빼고 빠르게
python scan.py -f urls.txt --no-comments
```
맥에서 `python`이 안 되면 `python3`로 실행하세요.

## 결과 보는 법
- `out/리포트_날짜시간.md`: 영상별 상세 리포트입니다. 메모장, VS Code, 노션에 붙여넣기 등으로 열면 됩니다.
- `out/구간목록.csv`: 실행할 때마다 아래에 이어서 쌓입니다. 구글시트나 엑셀에 그대로 붙여넣으면 소재 관리 시트가 됩니다.

## 키워드 바꾸기
`keywords.txt`를 메모장으로 열어 수정하세요. 이번 주 카테고리(예: 냄새)만 남기고 나머지 줄 앞에 `#`을 붙이면 결과가 깔끔해집니다.

## 잘 안 될 때
| 증상 | 해결 |
|---|---|
| `실패: ... Sign in / HTTP Error 4xx` | `pip install -U yt-dlp`로 업데이트합니다. 유튜브가 자주 바뀌어서 업데이트가 제일 흔한 해결책이에요 |
| JS 런타임 관련 경고 | 최신 yt-dlp는 유튜브 처리에 [deno](https://deno.com) 설치를 권장합니다. 경고만 나오고 결과가 나오면 무시해도 돼요 |
| "한국어 자막이 없어요" | 자막 없는 영상입니다. 그래프 최고점과 댓글 위주로 보세요 |
| 키워드 구간이 너무 많음 | `keywords.txt`에서 `매일`, `요즘`처럼 흔한 단어를 끕니다 |

# 쇼츠 자동 편집 (make_short.py)

레시피(JSON) 한 장으로 **원본 클립 → TTS 질문 → 원본 클립** 쇼츠를 만듭니다. 상단 제목 2줄, 하단 링크 안내와 출처, 짧게 끊은 자막(셀럽 대사는 흰 글씨, TTS는 노란 박스)과 줌 연출이 들어가고, TTS가 나올 때는 원본 소리가 작아집니다.

```bash
# 처음 한 번 설치
python3 -m pip install -U "yt-dlp[default]" edge-tts pillow imageio-ffmpeg

# 구간 시간만 미리 확인 (빠름)
python3 make_short.py recipes/백진희_발뒤꿈치밤.json --check

# 영상 만들기 → out/쇼츠_백진희_발뒤꿈치밤.mp4
python3 make_short.py recipes/백진희_발뒤꿈치밤.json
```

## 레시피 쓰는 법
- `title1`(빨강), `title2`(검정): 상단 제목 2줄
- `link_text`: 하단 안내 문구 (프로필 링크 번호)
- `parts`: 순서대로 이어 붙일 구간
  - `{"type": "clip", "from": "자막 문구 또는 04:16", "to": "자막 문구 또는 04:25"}`
  - `{"type": "tts", "text": "읽을 문장", "over": "이 장면 위에서 읽기(문구/시간, 생략하면 바로 앞 구간에 이어서)"}`
- 문구는 스캐너 리포트의 자막에서 **몇 글자만 그대로 복사**하면 됩니다. 띄어쓰기와 문장부호는 무시하고 찾아요.
- 폰트를 바꾸려면 `fonts` 폴더를 만들고 .ttf/.otf 파일을 넣으세요 (예: Pretendard Black).

## v2 변경점
- **원본 영상에 박힌 자막 가리기**: 원본 아래쪽 20%를 잘라내고 씁니다. 레시피의 `"src_crop_bottom": 0.2` 값으로 조절하세요. 원본 자막이 더 위에 있으면 0.25~0.3으로 올리면 됩니다.
- **컷 정밀도**: 자동자막의 단어별 시간으로 자르고, 말 사이 쉼에 맞춰 컷 위치를 보정해서 문구 뒤에 다른 말이 따라붙지 않게 했습니다.
- **자막**: 13자 안팎의 짧은 한 줄로 끊어서 말하는 타이밍에 맞춰 넘어갑니다. 셀럽 대사는 흰 글씨에 검정 테두리, TTS는 노란 박스예요.
- **연출**: 원본 구간은 천천히 줌인과 줌아웃을 번갈아 하고, TTS 구간은 확 당겨서 강조합니다.
- **소리**: TTS가 나오는 동안 원본 소리를 7%로 줄입니다.
- **TTS**: `gemini_key.txt`에 Google AI Studio 키를 넣으면 Gemini TTS를 씁니다. `python3 make_short.py --voice-test`로 여성 목소리 5종을 비교한 뒤 레시피 `"gemini_voice"`에 고른 이름을 적으세요.

## v3.1 연출
- 구간 사이에 **전환 효과**가 0.22초씩 들어가요. 줌인, 슬라이드, 흰 화면 번쩍, 위로 밀기, 원형 열림이 번갈아 나오고, 전환할 때마다 '슉' 효과음도 함께 나와요.
- 각 구간이 시작할 때 **툭 당겼다 풀리는 펀치 줌**이 들어가요. 원본 구간은 8% 줌인과 줌아웃이 번갈아 나오고, TTS 구간은 더 크게 당겨요.
- 레시피에서 끄는 법: `"transitions": false`, `"sfx": false`, `"punch_zoom": false`

## 자막 디자인 고르기
레시피에 `"sub_theme": "이름"`을 넣으세요. 기본값은 `clean`이에요.

| 이름 | 셀럽 대사 | TTS |
|---|---|---|
| `clean` | 반투명 검정 바 + 흰 글씨 | 초록 바 + 검정 글씨 |
| `variety` | 노란 굵은 글씨 + 두꺼운 테두리 + 그림자 (예능 자막) | 빨간 박스 + 흰 글씨 |
| `bubble` | 흰 말풍선 + 검정 글씨 | 검정 말풍선 + 흰 글씨 |
| `minimal` | 흰 글씨 + 얇은 테두리 + 그림자 | 초록 글씨 |
| `pop` | 흰 글씨 + 굵은 검정 테두리 (v2) | 노란 박스 |
