# 내 사주 명당 (앱인토스 미니앱, 가칭)

생일 하나와 사는 시군구로, 전국 시군구가 내 사주에 얼마나 맞는지 지도로 보여 주는 무료 미니앱입니다. 계산은 모두 휴대폰에서 하고(사이트 엔진 `../jojeong/lib` 그대로), 서버로 보내는 것은 없습니다.

| 화면 | 내용 | 공유 |
| --- | --- | --- |
| 내 운명의 동네 1위 | 시도마다 한 곳씩 뽑은 TOP5와 한 줄 이유 | 카드 A "너는 어디야?" |
| 이번 주말 명당 | 토요일, 일요일마다 그날 깨어나는 살로 거리(1시간 안팎, 반나절, 하루 코스)를 정하고 잘 맞는 곳 2곳씩. 매주 바뀜 | 없음 |
| 동네 성적표 | 지도를 눌러 그 동네의 순위(N곳 중 M위), 거리, 이유 | 카드 B "너희 동네는 몇 위야?" |
| 우리 둘의 동네 | 링크를 받은 사람이 생일을 넣으면 둘 다 좋은 동네 | 카드 C "너랑 나는 어디서 살까?" |

## 점수

- 사주 오행 50%: 지금 사는 곳에서 본 방향의 오행(북 수, 북동 토, 동 목, 남동 목, 남 화, 남서 토, 서 금, 북서 금)이 내 사주에 필요한 기운인지(`readChart`의 용신, 희신, 기신). 두 방향 사이는 각도로 섞는다.
- 팔택 50%: 사주의 해(입춘 기준)와 성별로 명괘를 구하고, 그 방향이 8별 중 무엇인지(생기 100, 천의 90, 연년 84, 복위 72, 화해 42, 육살 34, 오귀 26, 절명 14). 표는 『팔택명경』 하권 57쪽 총표(`claude/saju-db`의 `jojeong/knowledge/notes-bazhai.md`). 성별이 없으면 사주 오행만 본다.
- 지명 한자 점수는 2026-11-07 대표님 결정으로 뺐다(설득력이 없음).
- 바로 옆(0.06도 안)은 방향이 없어 순위에서 뺀다.

## 이번 주말 명당

- 그날의 점수: 사이트의 오늘의 운세(`todayFor`)를 그 날짜로 읽는다.
- 거리: 그날 지지에 깨어나는 살(`salsAt`). 역마면 하루 코스(100~260km), 화개면 1시간 안팎(10~45km), 그 밖은 반나절(30~120km). 시군구 중심점 사이 직선거리.
- 장소: 그 거리 안에서 위 점수가 높은 곳, 시도마다 하나씩 2곳. 토요일에 나온 곳은 일요일에 다시 내지 않는다.
- 오행별 장소 종류(숲, 바다 등)는 관례적인 해석이라 화면에서 단정하지 않는다.

## 데이터

- `src/data/regions.json`: `python3 -I scripts/regions2026.py <HangJeongDong_ver20261001.geojson>` (vuski/admdongkor, 2026-10-01 행정동 → 시군구 256곳).
- 행정구역이 바뀌면 스크립트를 다시 돌린다.

## 둘의 동네 링크

`intoss://hundo-dongne?with=<토큰>`. 토큰에는 이름, 사주 여덟 글자, 사는 시군구 코드, 명괘 번호(한 자리, 성별을 넣은 경우)만 든다(생일, 출생 연도, 주소는 없음).

## 개발

```bash
ln -s ../hundo-toss/node_modules node_modules   # 또는 npm install
npm run dev
npm run typecheck
```

## 출시 전에 할 일

1. 앱인토스 콘솔에 미니앱 "내 사주 동네"를 만들고 이름을 `apps-in-toss.config.ts`의 `appName`(`hundo-dongne`)과 맞춘다.
2. 카드 저장(`File.saveBase64`)과 공유 링크를 토스 앱 샌드박스에서 확인한다.
3. `npm run build`, `npm run deploy`.
