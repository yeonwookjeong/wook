# 콘솔 등록 자료 (내 사주 명당)

2026-11-11 정리. 공식 문서 사이트(developers-apps-in-toss.toss.im)는 이 작업 환경에서 열리지 않아 검색 발췌와 커뮤니티 글로 확인했다. "확인 필요"는 콘솔 화면에서 직접 맞춰 본다.

## 입력값

| 항목 | 값 | 비고 |
| --- | --- | --- |
| appName | `hundo-dongne` | 한 번 정하면 못 바꿈. `apps-in-toss.config.ts`와 같아야 함 |
| 앱 이름 | 내 사주 명당 | 공백 한 칸씩. 앱 정보 이름과 번들 이름이 다르면 반려 사례 있음 |
| 부제 (20자 안) | 내 사주에 맞는 동네는 어디일까? | 18자. 느낌표 금지, 물음표는 됨 |
| 카테고리 | 생활 > 콘텐츠 > 운세 | 확인 필요 (비공식 목록 기준) |
| 검색 키워드 (10개) | 사주, 명당, 동네, 풍수, 이사, 운세, 오행, 배산임수, 주말 나들이, 약속 장소 | |
| 사업자 | 없어도 됨 | 무료, 광고 없음, 로그인 없음 기준. 광고를 붙이면 수익 5천 원 전에 등록 |

## 상세 설명 (200~500자, `-` `■` 같은 기호 금지)

내 사주에 부족한 기운을 채워 주는 동네를 찾아 드려요. 생일과 태어난 시간, 지금 사는 곳만 고르면 우리 지역에서 나와 가장 잘 맞는 동네와 그 안의 동까지 순위로 보여 드려요. 산과 숲, 강과 바다, 논밭, 날씨 같은 실제 땅의 모습을 다섯 가지 기운으로 읽어서 왜 잘 맞는지 이유도 함께 알려 드려요. 전국 순위와 지도, 이번 주말 나들이 추천, 친구들과 만나기 공평한 약속 장소와 날짜도 볼 수 있어요. 마음에 드는 결과는 카드로 저장하거나 친구에게 보낼 수 있어요.

## 이미지

| 파일 | 규격 | 상태 |
| --- | --- | --- |
| `icon-600.png` | 600×600, 배경 있음, 모서리 직각 | 글자 없이 산, 물, 붉은 해 |
| `thumb-1932x828.png` | 가로 썸네일 | 규격이 1932×828과 1504×741 두 가지로 알려져 있음. 콘솔 미리보기에서 확인 필요 |
| `screen-1~3-636x1048.png` | 세로 스크린샷 3장 | 선택 항목. 1 우리 지역 1위, 2 전국 지도와 동네 성적표, 3 약속 명당 |

다시 만들기: 스크래치 스크립트(`icon.html`, `thumb.html`, `shoot10.mjs`)로 개발 서버 화면을 찍고 636×1048로 줄였다.

## 순서

1. 워크스페이스에서 앱 "+ 등록", 위 값 입력 (임시저장 가능)
2. `npm run build` 후 `npx ait token add`, `npx ait deploy -m "첫 버전"`
3. 콘솔 "테스트"에서 QR로 한 번 이상 열어 보기 (그래야 "검토 요청"이 켜짐)
4. 검토 요청: 앱 정보 영업일 1~2일, 번들 최대 3일 안팎
5. 승인 메일 뒤 "출시하기"
