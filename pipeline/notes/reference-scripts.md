## 레퍼런스 1·2 (같은 제작자)에서 반복되는 뼈대
1. **첫 줄 = "여기 ~이 있습니다" + 이상한 점 하나.** 화면 속 대상을 가리키며 시작. 질문 아님.
   - "여기 서울 한복판에는 강인데 흐르지 않는 물이 있습니다."
   - "여기 성문을 노리는 적군이 옵니다."
2. **문제 → 해결 → 새 문제 → 새 해결 사슬.** 2~3줄마다 전환어: 그런데 / 그래서 / 문제는 / 그러자 / 이번엔 / 하지만.
   - 철옹성: 문 → 충차 → 해자 → 접이식 다리 → 옹성 → 불 → 오성지 → 사다리 → 치 → 화살 → 여장 → 사각지대 → 현안.
   - 한강: 물 빠짐·범람 → 강바닥 파기 → 물이 더 빠짐·짠물 → 하구 막으면? 안 됨 → 수중보.
3. **기능 먼저, 이름은 보상으로.** "…이걸 해자라고 부릅니다", "이게 바로 오성지입니다".
4. **시청자 반론을 대신 말함.** "그럼 하구를 아예 막아버리면 되지 않냐구요?"
5. **외우기 쉬운 숫자 장치.** "구멍 5개, 한 손 손가락 수만큼", "홈 12개, 한 해 달 수만큼".
6. **한 줄 2~3초, 구어 어미.** ~죠 / ~거든요 / ~구요 / ~습니다 섞기.
7. **끝 = 지금도 볼 수 있는 증거 + 서명 문장.** "팔달문 옹성엔 지금도 홈이 12개" → "철옹성은 이렇게 탄생한 겁니다". 명령형으로 끝나지 않음.
8. **길이가 길다.** 96초, 179초. 사슬이 길어서 끝까지 보게 만듦.
