## 레퍼런스 1·2 (같은 제작자)에서 반복되는 뼈대
1. **첫 줄 = "여기 ~이 있습니다" + 이상한 점 하나.** 화면 속 대상을 가리키며 시작. 질문 아님.
   - "여기 서울 한복판에는 강인데 흐르지 않는 물이 있습니다."
   - "여기 성문을 노리는 적군이 옵니다."
2. **문제 → 해결 → 새 문제 → 새 해결 사슬.** 2~3줄마다 전환어: 그런데 / 그래서 / 문제는 / 그러자 / 이번엔 / 하지만.
   - 철옹성: 문 → 충차 → 해자 → 접이식 다리 → 옹성 → 불 → 오성지 → 사다리 → 치 → 화살 → 여장 → 사각지대 → 현안.
   - 한강: 물 빠짐·범람 → 강바닥 파기 → 물이 더 빠짐·짠물 → 하구 막으면? 안 됨 → 수중보.
3. **기능 먼저, 이름은 보상으로.** "…이걸 해자라고 부릅니다", "이게 바로 오성지입니다".
4. **시청자 반론을 대신 말함.** "그럼 하구를 아예 막아버리면 되지 않냐구요?"
5. **외우기 쉬운 숫자 장치.** "구멍 5개, 한 손 손가락 수만큼", "홈 12개, 한 해 달 수만큼".
6. **한 줄 2~3초, 구어 어미.** ~죠 / ~거든요 / ~구요 / ~습니다 섞기.
7. **끝 = 지금도 볼 수 있는 증거 + 서명 문장.** "팔달문 옹성엔 지금도 홈이 12개" → "철옹성은 이렇게 탄생한 겁니다". 명령형으로 끝나지 않음.
8. **길이가 길다.** 96초, 179초. 사슬이 길어서 끝까지 보게 만듦.

# 9편 비교 분석 (2026-11-08)

모든 편이 같은 틀: "여기 ~" 첫 줄 → 문제·해결 사슬 → 중간 "아주 환장할 노릇이죠" → "~은 이렇게 탄생한 겁니다". 길이 126~179초.
**틀이 같은데 조회수가 10배 차이 → 갈린 건 소재와 첫 10초.**

| 조회수 | 편 | 첫 줄 유형 | 갈등 등장 |
|---|---|---|---|
| 41만 | 라하이나 | 특정 장소의 **이상한 장면** + 통념("기적의 집") 뒤집기 | 0초 |
| 30만 | 서울숲 | 아는 장소 + **돈**("4조 원 남는 땅") + 결정 드라마 | 0초 |
| 21.6만 | 철도 신호 | 뉴스(스페인 추돌) + 위기 장면 | 9초 |
| 17.8만 | 한옥 문 | 일반 상황("겨울바람이 옵니다") | 9초 |
| 16.6만 | 김치광 | 일반 상황("추위가 옵니다") | 14초 |

| 5.5만 | 타이베이 101 | 좋은 이미지지만 **숫자 5개를 20초에 쏟음** | 34초 |

## 위쪽에만 있는 것
1. **특정한 장소 하나 + 사람들이 믿는 통념** → 첫 줄에서 뒤집기 예고. ("기적의 집이 아닙니다", "4조를 버린 땅")
2. **사람과 결정.** 집주인 부부, 서울시·LG. 기술보다 선택의 드라마.
3. **두 번째 반전 + 정직.** 라하이나: "반전은 따로 있습니다. 지붕은 흰개미 때문에 바꿨고… 부부가 직접 말했죠. 운도 따랐다고 인정합니다."
4. **지금 가서 볼 수 있는 것**으로 끝. (서울숲 사슴·곤충식물원, 라하이나 재건)

## 아래쪽에 있는 것
- "여기 ~가 옵니다" 일반 상황으로 시작 (장소가 특정되지 않음)
- 뉴스로 끌고 본문은 다른 얘기 (구룡마을, 확성기)
- 갈등 전에 숫자 나열 (타이베이)

주의: 업로드 날짜·시간, 알고리즘 운은 반영 못 함. 한 채널 표본이라 다른 채널로 교차 확인 필요.

## 토리블 가설 갱신 (표본 11개: 건축사전 11편 + 영어 2편)
