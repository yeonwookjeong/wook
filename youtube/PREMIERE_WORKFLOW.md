# Premiere 작업 순서: 쇼츠 1편 만들기

역할: **창작 판단(컷 고르기, 디자인, 최종 편집)은 내가**, 찾기·정리·글쓰기·검수는 Claude Code가.
맥 Claude Code는 `cd ~/wook && claude -r` → "만타 여행 유튜브"에서 시작한다.

## 1. 기획 (Claude Code)
> 오늘 만들 쇼츠는 ○○야. youtube/catalog 랑 shorts_plan.md 보고 시안 2~3개 뽑아줘.

- 시안마다 첫 화면 문구, 구성표(원본 / 구간 / 내용), 폴라로이드 문구가 나온다
- 하나를 고르면 → 2단계

## 2. 컷 목록 만들기 (Claude Code)
> 시안 ○번을 컷 목록 CSV로 만들어서 youtube/cuts/ 에 저장해줘.

형식 (`youtube/cuts/예시.csv`):
```
clip,in,out,note
GX010174,0:00,0:03,경기장에서 쏟아지는 인파
GX010174,0:12,0:20,7만 명이 한꺼번에 쏟아졌으니
53번 버스 내리고 숙소가는길 1,0:16,0:30,너무 다행이다
```
- `clip`: 파일 이름(확장자 없이). 이름이 같은 파일이 여러 개면 `3일차/IMG_5653.MOV`처럼 경로로 쓴다
- `note`: 내레이션이나 자막 아이디어. Premiere에서 **시퀀스 마커**로 보인다

## 3. 러프 컷 타임라인 만들기 (Claude Code)
> 그 컷 목록으로 Premiere XML 만들어줘.

직접 실행할 때:
```bash
cd ~/wook && ~/.venvs/footage/bin/python youtube/tools/cutlist_to_xml.py youtube/cuts/예시.csv \
  --footage "/Volumes/T7/여행영상/2023 영국/영상"
```
- 기본은 세로 1080x1920, 29.97fps. 롱폼은 `--size 1920x1080`
- 원본은 경로만 가리킨다. 복사하거나 수정하지 않는다

## 4. Premiere에서 열기 (나)
1. **파일 > 가져오기**에서 `.xml` 선택 → 프로젝트 패널에 시퀀스가 생긴다
2. 시퀀스를 열면 클립이 순서대로 깔려 있고, 마커에 내레이션 메모가 있다
3. GoPro 가로 영상은 세로 화면 가운데에 작게 놓인다 → 클립마다 크기와 위치를 맞추거나 **시퀀스 > 자동 리프레임 시퀀스** 사용
4. "미디어 오프라인"이 뜨면 T7이 연결됐는지 확인하고 **미디어 연결**로 원본 폴더를 지정한다
5. 여기서부터 컷 길이, 전환, 색, 자막 디자인은 직접

## 5. 내레이션과 자막 (나 + Claude Code)
- 녹음은 휴대폰 음성 메모로 충분하다. 한 줄씩 끊어서 녹음
> 바탕화면 녹음 파일 받아쓰기해서 SRT 만들어줘. 한 줄 15자 이하.
- Premiere: **파일 > 가져오기**로 `.srt`를 불러와 타임라인에 올리면 캡션 트랙이 된다

## 6. 내보내기 전 검수 (Claude Code)
> 바탕화면에 내보낸 최종본 검수해줘.

확인 항목: 길이 60초 이내 / 첫 2초 화면과 문구 / 블러가 빠진 얼굴 / 다른 사람이 만든 화면(영화, 중계, 스톡) / 소리 크기 / 끝의 폴라로이드

## 7. 올리기와 기록 (Claude Code)
> 제목 5개, 설명, 해시태그, 첫 화면 문구 후보 만들어줘.
> 오늘 한 거 PROGRESS.md 에 정리하고 커밋해줘.

## 참고
- `cutlist_to_xml.py`는 Final Cut Pro 7 XML 형식으로 만든다. Premiere가 공식 지원하는 가져오기 형식이다
- 클라우드에서 가짜 영상으로 시간 계산, 한글 경로, 소리 없는 클립, 오류 메시지까지 확인했다. **실제 Premiere에서 열어본 건 첫 사용 때가 처음**이니, 이상하면 화면을 캡처해서 알려줄 것
