# EP05 연출 설계도 — 한국 나이가 줄어든 날 (2026-11-21)

화풍: 민화풍 배경(그림) + 먹선 졸라맨(코드). 대본·음성은 확정본(`scripts/ep05.md`, `studio/src/ep05/vo_*.json`) 그대로.
시간은 영어판 기준(전체 약 35초). 스페인어판은 같은 박자를 문장 길이 비율로 맞춘다.

## 1. 참고 작품 (배울 것 / 베끼지 않을 것)
- 숫자 하나가 바뀌는 순간을 이야기의 중심에 두는 설명 쇼츠들 → **배울 것:** 한 화면에 생각 하나, 숫자가 바뀌는 순간을 화면 가운데·크게·소리와 함께. **베끼지 않을 것:** 캐릭터, 레이아웃, 음악.
- 생일 카운트다운·새해 카운트다운 장면의 리듬 → **배울 것:** "3, 2, 1" 박자에 컷을 맞추는 긴장감.

## 2. 구조 후보 3개 → 선택
1. **풍선 하나의 일생**: 아기 풍선 숫자가 1 → 2 → (세 개로 분열) → 줄어듦 → 그대로인 곳 → "?" 로 끝남. *(선택)*
2. 달력 넘기기: 달력 한 장이 계속 넘어가며 시대가 바뀜.
3. 법정 판결: 2023년 법이 망치로 쾅 → 과거 회상.

**선택 이유:** 1번은 시작(아기 풍선 "1")과 끝(시청자 풍선 "?")이 같은 물건이라 처음과 끝이 맞물리고, 숫자 변화가 한눈에 보인다. 2·3번은 사람이 덜 나와 지루해질 위험.

**이 화풍만 할 수 있는 장면(핵심 한 번):** 4번 문장 "Overnight" — 공원 사람들 머리 위 풍선이 **한꺼번에 툭툭 줄어들며** 숫자가 내려간다. 전체 영상의 절정.
