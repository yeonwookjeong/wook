# 코노라마 화풍 기준서 (v1, 2026-11-15)

목표: 유행을 타지 않고, 어느 장면을 캡처해도 "코노라마"로 보이는 그림.
방식: 부품(PNG)을 미리 만들어 두고 Remotion에서 배치·움직임만 한다. 글자는 전부 코드로 얹는다.

## 1. 화풍 한 줄
**깨끗한 윤곽선 그림책 일러스트 (ligne claire).** 균일한 진갈색 윤곽선, 평평한 색 + 그림자 한 단계, 은은한 종이 결.
- 왜: 반짝이는 3D 점토나 유리 질감은 지금 유행이라 2~3년 뒤 낡아 보인다. 윤곽선 그림책 화풍은 수십 년째 낡지 않는다.
- 하지 않는 것: 그라데이션 하늘, 렌즈 빛번짐, 반짝이 장식, 네온 글로우, 사진 질감, 3D 렌더 느낌.

## 2. 색 (이 8색만 쓴다)
| 이름 | 코드 | 쓰는 곳 |
|---|---|---|
| 먹색 (윤곽선) | #2A1C24 | 모든 윤곽선, 글자 |
| 한지 크림 | #F3EDE2 | 기본 바탕, 밝은 면 |
| 남색 | #26386B | 주 색, 자막 띠, 정장 |
| 다홍 | #E2574C | 강조, 지붕, 도장 |
| 단청 초록 | #3E8E7E | 보조 강조, 식물, 표지 |
| 개나리 | #F2C14E | 핵심 단어 강조, 말풍선 |
| 살구 (피부 기본) | #F4D0B0 | 피부 |
| 흙색 | #A8744A | 나무, 마루, 가구 |
그림자: 각 색을 15% 어둡게 한 한 단계만. 빛은 항상 왼쪽 위 → 그림자는 오른쪽 아래.

## 3. 채널 고유 장치 (매 편 반복해서 기억에 남게)
1. **붉은 도장**: 핵심 단어가 나올 때 다홍 도장이 '쾅' 찍힌다 (예: OUR, 만 나이). 한국적이고 유행을 안 탄다.
2. **이름표 꼬리표**: 물건에 붙는 남색 꼬리표 (OUR HOUSE 같은 것). 모양 고정.
3. **자막 띠**: 화면 아래 남색 띠 위 흰 글씨, 강조 단어만 개나리색. 그림 위에 글자를 바로 얹지 않는다.
4. **무대 카드**: 장면은 둥근 모서리 카드 안의 작은 무대처럼 보인다. 바깥은 한지 크림 바탕.
5. **마지막 질문 카드**: 끝 장면은 항상 같은 질문 카드 모양 (댓글 유도).

## 4. 화면 규칙 (9:16, 1080x1920)
- 위 0~250px: 비움 (유튜브·틱톡 UI)
- 250~1350px: 무대 (그림)
- 1400~1650px: 자막 띠
- 오른쪽 140px 세로 띠: 글자 금지 (좋아요·댓글 버튼)
- 한 화면에 주인공 하나. 소품은 최대 3개.

## 5. 부품 만드는 규칙 (Gemini·Envato 공통)
- 모든 생성 문장 앞에 아래 **고정 문장**을 그대로 붙인다.
- 배경은 단색 한지 크림(#F3EDE2) → 배경 지우기는 코드로 한다.
- **그림 안에 글자 금지.** 간판·신문·명패의 글자는 빈칸으로 받고 코드로 넣는다 (AI가 한글을 망가뜨림).
- 실제 상호·로고 금지.
- 사람은 한 번에 "같은 사람 6가지 포즈" 시트로 받는다 (따로 뽑으면 얼굴이 달라짐).
- Envato 소재는 위 화풍과 색이 맞을 때만 쓴다. 안 맞으면 색만 바꿔 쓰지 말고 버린다.

### 고정 문장 (모든 생성 앞에 붙임)
```
Clean ligne claire picture-book illustration, uniform dark brown outlines (#2A1C24), flat colors with exactly one soft shadow tone, light from top left, subtle paper grain, limited palette: cream #F3EDE2, navy #26386B, vermilion #E2574C, jade green #3E8E7E, mustard #F2C14E, warm wood #A8744A, skin #F4D0B0. Cute rounded proportions, simple dot eyes with a small highlight. Plain flat cream (#F3EDE2) background, centered, no text, no letters, no logos, no watermark.
```
